# 测试质量、关键材料与指标解释

本页依据[13 测试表征](../references/kd/13_cell_testing_characterization.md)、[14 关键材料](../references/kd/14_key_materials.md)及相关工艺资料。原文数字均属**资料参考**；实际检验规范、分档和判废界限仍须具体产品版本支持。

## 1. 电性能指标与单位

以下定义见[13 §1–2](../references/kd/13_cell_testing_characterization.md)。

| 指标 | 原文定义/单位 | 解释边界与工作建议 |
|---|---|---|
| STC | 辐照度1000 W/m²、AM1.5G、电池温度25°C | 比较性能时记录实际条件及是否作修正；STC不是车间环境温度 |
| Isc | 短路电流，A | 不与电流密度Jsc（mA/cm²）混用，跨面积比较需面积依据 |
| Voc | 开路电压，V或mV | 单片和组件量级不同；仅凭Voc低不能断定单一工艺原因 |
| Pmax | Imp × Vmp，W | 用最大功率点量，不以Voc × Isc代替 |
| FF | Pmax/(Voc × Isc)，无量纲 | 0.83与83%要显式换算；输入V/mV、A/mA须一致 |
| η | Pmax/(辐照度 × 面积)，无量纲 | 面积需匹配定义和m²单位；百分数输出乘100，电池效率与组件效率分别标注 |
| Rs、Rsh | 串联/并联电阻 | 原文也给Ω·cm²表述；必须确认原始量是Ω还是面积归一值 |
| J₀、ρc | 复合电流密度、接触电阻率 | 不等同于I₀、Rs或方块电阻，见[15 §3.10](../references/kd/15_tube_furnace_equipment.md) |

**工作建议**：公式计算前检查单位、有效面积、测试条件及测量对象；效率异常时先查单位与分母，不用裁剪到“典型范围”掩盖问题。效率由25%变25.5%应表述为增加0.5个百分点；相对增幅另算并注明分母。

## 2. 检测方式决定证据能力

| 方法 | 原文说明 | 可以支持什么；需要避免什么 |
|---|---|---|
| 光照I-V/闪光测试 | 测Voc、Isc、Pmax、FF及效率 | 评估电性能与分档；记录校准、温度和对象 |
| EQE/SR | 观察不同波长的载流子收集和光谱响应 | 区分光谱段问题；积分关系需明确输入为光子通量还是光谱辐照度及对应单位 |
| EL | 外加正向电流成像，观察暗纹、暗区等特征 | 可形成隐裂、断栅、接触等候选缺陷；单个亮暗特征不足以确认唯一类别 |
| PL | 光激发，表征寿命与复合的空间分布，可用于中间工序 | 标明激励和检测阶段；不能与EL强度直接合并 |
| 暗I-V | 分析二极管特性，提取电阻、理想因子等 | 与光照I-V区分；模型拟合结果保留拟合区间与假设 |
| Suns-Voc | 排除串联电阻影响，得到伪FF等 | pFF与FF差可辅助分析接触/电阻损失，须统一条件 |
| µW-PCD/QSSPC | 少子寿命测量 | 方法、注入水平和样品结构不同，比较前需对齐条件 |
| IR热成像 | 观察热斑、接线盒、焊带等局部温度 | 温度图支持定位候选异常；不能由热点位置单独确认根因 |
| AOI/四探针等在线检测 | 外观、反射、方块电阻、印刷等 | 缺陷名、算法版本、测点与抽检覆盖范围要一同保存 |

来源：[13](../references/kd/13_cell_testing_characterization.md)，§2–10。上述“避免”及条件记录为**工作建议**。

## 3. 质量数据关联方式

以下为**工作建议**，不代表现有系统已提供这些字段：

- 以实际可追溯对象关联：产品/片/组件、批次、工序、设备/炉管、舟和位置、测试阶段、测量时刻、配方版本。
- 同对象多次测试保留重测序号和原因；首测良率、最终良率、返修恢复率分别定义，不能静默选最高结果。
- 分开记录设备测量值、派生指标、检测算法标签和人工复判；不要用文献典型范围生成“已确认不良”标签。
- 质量与工艺时间关联要以实际加工区间为准；同日同设备的相关性不足以证明片级经历。
- 对抽检数据报告样本数、覆盖范围及缺失情况；不能把抽检结果无条件扩展成全批判定。
- 对质量异常先分产品、路线、版本和测量方法，再看设备、舟位置及维护变化；结论分“观察”“候选原因”“已验证原因”。

## 4. 材料与工艺适配

| 材料/材料组 | 资料事实 | 对数据、文档或程序的影响（工作建议） | 来源 |
|---|---|---|---|
| 高温/低温银浆 | PERC/TOPCon等常用高温银浆；HJT使用低温体系 | 浆料类型与固化/烧结路线一同记录，不能只以“银浆”合并参数 | [14](../references/kd/14_key_materials.md)，§2.4；[08](../references/kd/08_hjt_cells.md)，§3 |
| 铝浆 | 主要用于Al-BSF及PERC背面接触 | 不把PERC背铝金属化假定到TOPCon双面银结构 | [14](../references/kd/14_key_materials.md)，§3；[07](../references/kd/07_topcon_cells.md)，§7 |
| EVA/POE/EPE | 封装胶膜在阻水、粘接、温度与成本方面有差异 | 层压分析保留材料结构及批次；文献差异不能自动推出特定批次异常 | [14](../references/kd/14_key_materials.md)，§4 |
| TCO/ITO | HJT透明导电层用于横向导电等功能 | 膜厚、电阻、透光与层位应配套解释，不与SiNₓ膜混合 | [08](../references/kd/08_hjt_cells.md)，§3 |
| 焊带/ECA | 焊带与导电胶为不同互联体系；HJT有低温互联需求 | 工艺温度和拉力等检验条件需匹配实际互联材料 | [14](../references/kd/14_key_materials.md)，§6；[11](../references/kd/11_module_manufacturing.md)，§3 |
| POCl₃、BCl₃/BSG | 分别关联磷、硼掺杂；BSG还可能承担保护作用 | 不按气体中文简称猜正背面用途；保存气源、路线及步骤 | [14](../references/kd/14_key_materials.md)，§7；[15](../references/kd/15_tube_furnace_equipment.md)，§1.7 |
| SiH₄、NH₃、PH₃、TMA等 | 具有不同沉积用途和危险属性 | 普通知识页不能替代现场物料编码、安全资料与供气联锁 | [14](../references/kd/14_key_materials.md)，§9 |

## 5. 需要保留的原文问题

| 问题 | 原文位置 | 使用约束 |
|---|---|---|
| 银浆单耗单位标题不一致 | 14 §2.4表头为“单耗(g/片)”，单元格却为80–120 mg/片等 | 保留原始单位并标注冲突，不把数字直接解释成g/片 |
| 寿命参考不同 | 13 §8给TOPCon>500 µs，§11给N型硅片>1 ms | 对象和条件未完全一致，不合成为统一来料标准 |
| EQE/SR积分输入符号需明确 | 13 §3.1以Φ表示光子通量，§3.3使用SR与Φ积分 | 计算前澄清光子通量/光谱辐照度及单位；不要直接复制符号实现公式 |
| HJT温度表述冲突 | 08 §3/§5与§4的<200°C及200–250°C | 不能凭本文选定固化温度，见[工艺路线](process-map.md)冲突表 |
| 合格界限与标准版本缺少现场依据 | 13典型范围、14材料性能及11测试描述 | 只能作为检索线索；验收须查实际产品规范和适用标准版本 |
| 成本与市场数据带时期 | 14 §2、§10–11及07相关章节 | 保留2025年等原文时间和成本分母；不得称为当前报价或本厂BOM占比 |

# 光伏制造工艺与技术路线

本页为原资料的检索与任务解释层，不是本厂工艺规程。标记含义：**资料事实**为原文陈述，**参考值**为原文示例或历史范围，**工作建议**为便于分析形成的推导，**待确认**为现场信息缺口或原文冲突。实际产品、设备、配方及版本优先使用当前任务提供且已确认的资料。

## 1. 产业链与对象边界

| 阶段 | 输入 → 输出 | 应区分的对象 | 来源 |
|---|---|---|---|
| 硅原料提纯 | 冶金级硅 → 高纯硅料 | 原料、纯度等级、杂质含量 | [01 硅原料提纯](../references/kd/01_silicon_purification.md)，§2–5 |
| 晶体生长 | 硅料 → 单晶棒或多晶锭 | CZ直拉、FZ区熔、多晶铸锭 | [02 晶体生长](../references/kd/02_crystal_growth.md)，§1–3 |
| 硅片制备 | 棒/锭 → 硅片 | 切割、损伤去除、制绒、清洗 | [03 硅片制备](../references/kd/03_wafer_preparation.md)，§1–4 |
| 电池制造 | 硅片 → 电池片 | 衬底类型、发射极、钝化接触、金属化 | [04 电池基础工艺](../references/kd/04_cell_processing_basics.md)，§1–6 |
| 组件制造 | 电池片 → 封装组件 | 分档、串焊、叠层、层压、最终检测 | [11 组件制造](../references/kd/11_module_manufacturing.md)，§1–2 |

**工作建议**：分析产出、效率或缺陷时，先标明计量对象是硅片、电池片、电池串还是组件。单片数、批次数、串数、块数不能直接相加；面积也不能从产品名称猜定。

## 2. 电池路线决定工序含义

| 路线 | 结构/工艺识别点（资料事实） | 对任务的影响（工作建议） | 来源 |
|---|---|---|---|
| Al-BSF | 前侧发射极、全面积铝背场、丝网印刷及共烧结 | 不套用TOPCon背面隧穿层指标 | [05 丝网印刷电池](../references/kd/05_screen_printed_cells.md)；[06](../references/kd/06_perc_cells.md)，§2 |
| PERC | P型衬底；磷扩形成前侧N+发射极；背面AlOₓ/SiNₓ钝化及激光局部开口 | 激光开口与LECO不是同一工序；局部铝接触与TOPCon接触结构不同 | [06 PERC](../references/kd/06_perc_cells.md)，§2–5 |
| TOPCon | 常见为N型衬底、正面P+硼发射极、背面SiOₓ/poly-Si(n+)钝化接触 | 先确认LPCVD、PECVD或其他沉积路线，再解释工序和参数 | [07 TOPCon](../references/kd/07_topcon_cells.md)，§2、§5 |
| HJT/SHJ | c-Si与本征/掺杂a-Si:H形成异质结，TCO横向导电，低温金属化 | 不能套用TOPCon高温烧结条件；PECVD可能用于a-Si:H，而非SiNₓ ARC | [08 HJT](../references/kd/08_hjt_cells.md)，§2–4 |
| IBC | 交指式背接触结构，减少正面遮光 | IBC属于接触布局，可能与HJT等结合；不要当成互斥的材料路线 | [09 高效结构](../references/kd/09_high_efficiency_cells.md)，§4 |
| 钙钛矿及叠层 | ABX₃吸收层，可用作硅叠层顶电池；有旋涂、狭缝等制备方式 | 标明单结/叠层及面积；不能拿实验室小面积效率直接代替量产组件效率 | [12 钙钛矿](../references/kd/12_perovskite_cells.md)，§2、§4、§7 |

## 3. TOPCon的工序检索图

以下为[07 §3](../references/kd/07_topcon_cells.md)与[15 §5.2](../references/kd/15_tube_furnace_equipment.md)所描述的LPCVD示例顺序，仅用于定位知识：

```text
N型硅片 → 制绒/抛光与清洗
→ 背面SiOₓ隧穿层 → LPCVD硅膜 → 磷掺杂/晶化
→ 去绕镀 → 正面硼发射极 → BSG去除
→ 正面AlOₓ及正背面SiNₓ → 丝印/烧结 → LECO（可选） → I-V分选
```

**待确认**：15的“概述”又将硼扩散放在氧化前，不能据此生成唯一的现场工艺顺序。以产品实际工艺路线及配方版本为准；相关冲突见下节。

| 工序/术语 | 业务含义（资料事实） | 查数或读程序时要保留的区分（工作建议） |
|---|---|---|
| 隧穿氧化层 | 超薄SiOₓ兼顾界面钝化与载流子传输 | 湿化学、热氧化、等离子氧化；氧化步骤与硅膜沉积步骤 |
| poly-Si沉积 | 形成背面钝化接触硅层，沉积态可能还需晶化 | 沉积温度、退火温度、最终膜结构不是同一字段 |
| 原位/非原位掺杂 | 可在沉积中用PH₃掺杂，或另用POCl₃扩散 | “LPCVD”不能自动推断必有单独磷扩工序 |
| 去绕镀 | 清除正面/边缘寄生硅膜，保留背面功能层 | 保护层、单/双面处理、工艺路线；仅有时间不能认定清洗充分 |
| BSG/PSG | 分别为硼硅玻璃/磷硅玻璃 | 不按“玻璃层”合并；生成、保护与去除阶段有不同含义 |
| SE | 接触区与非接触区差异化掺杂 | 方块电阻的区域和测点必须一起保存 |
| LECO | 烧结后的激光增强接触优化 | 与SE激光掺杂、PERC激光开口分别编码 |

本表来源：[07](../references/kd/07_topcon_cells.md)，§3–8；[15](../references/kd/15_tube_furnace_equipment.md)，§1.7–1.8、§3.4–3.5、§4.4。

## 4. 组件流程与检测位置

**资料事实**：[11 §2](../references/kd/11_module_manufacturing.md)包括来料检验/分选、串焊、串后EL、叠层、层压、修边、层压后EL、装框、接线盒安装、最终测试及包装。

**工作建议**：同一组件的串后、层压后、最终EL是不同检测事件。比较缺陷时对齐检测阶段、组件标识及返修关系；不能把多次测试当成多个组件，也不能直接用后测缺陷证明前工序是原因。电池分档信息可用于解释串内失配，但要有实际串片对应关系。

## 5. 原文冲突与适用性限制

| 议题 | 原文位置及差异 | Agent应如何处理 |
|---|---|---|
| TOPCon顺序 | 15概述先硼扩再氧化；07 §3、15 §5.2先背面接触与去绕镀再硼扩 | 保留两种描述，引用具体章节；不把示例顺序固化为通用校验规则 |
| 硼扩温度 | 07 §3写BCl₃为800–1000°C；15 §1.4写常用1000–1050°C | 标明不同资料范围，等待实际设备/配方；不得取并集作为合格窗口 |
| TOPCon方块电阻 | 07 §3约100–150 Ω/sq；15 §1.4均匀发射极70–100 Ω/sq，SE不同区域另有范围 | 保留结构、区域及工序条件，不合成统一阈值 |
| HJT温度 | 08 §3/§5写低温或全程<200°C，§4流程却写200–250°C退火 | 不输出统一的最高允许温度；查证具体层结构、浆料和配方 |
| 行业统计与效率纪录 | 00、07、08、10、12含2024–2026年历史值、预测和记录 | 保留原文日期及实验室/量产/电池/组件标签；需要“当前最新”时另查原始权威来源 |

## 6. 任务开始时的最小业务上下文

以下是**工作建议**，不是原资料已具备的现场事实：

- 数据分析：产品路线、对象粒度、批/舟/炉管关系、工序与时间范围、单位及测量条件。
- 文档编写：读者和用途、工艺路线、引用版本、是否为培训材料或现场执行文件。
- 程序修改：输入输出契约、字段真实含义、关联键、参数配置及既有验证方式。
- 若材料不足，可先做结构识别与描述性分析，把缺少的映射单列；不得虚构设备清单、工艺许可范围或已批准的OEE口径。

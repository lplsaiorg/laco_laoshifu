# 数据处理与分析工作流

本文件是为 Agent 提出的工作约定，不是现场已批准的数据规范。工艺解释查阅[工艺图谱](../knowledge/process-map.md)、[设备知识](../knowledge/equipment.md)和[质量与材料](../knowledge/quality-and-materials.md)；冲突查阅[缺口清单](../knowledge/gaps-and-conflicts.md)。

## 先确定分析对象

接到 CSV、Excel、数据库结果或日志后，先识别技术路线、工序、设备形态、记录粒度与问题：是在比较产能、识别过程异常、分析质量，还是计算 OEE。未知字段先从实际样本、已有代码和用户文件推断候选含义，并标注推断。

原资料描述管式设备、炉管、承载舟和硅片，但没有给出现役设备台账、数据库或状态码。参考[15 一/1.2、四/4.2](../references/kd/15_tube_furnace_equipment.md)。以下关联键是建议字段，必须映射实际列名后使用：

| 对象 | 建议保留的键/上下文 | 避免的错误 |
|---|---|---|
| 整机/炉管 | `equipment_id`、`tube_id`，及炉管归属有效期 | 将多炉管并行运行时间相加后当成整机自然时长 |
| 批次/舟 | `batch_id`、`boat_id`、装载/卸载事件、投入片数 | 假定一舟恒等于一批，或以额定载片量替代实际投入 |
| 工序/配方 | `process_step`、`recipe_id`、`recipe_version`、技术路线 | 将氧化、沉积、清洗及不同版本配方直接混合比较 |
| 采样点 | 时间戳、温区/传感器、测量值、单位、数据质量码 | 混用设定值与实测值，或把多个温区均值当原始测点 |
| 单片/质量记录 | 单片或样本键、上游批次、测试时间、测试条件 | 把抽检结果扩展为全批良率，或把重测片重复计数 |

现场未提供对象关联时，不凭时间接近就断定批次归属。可以给出匹配候选及时间差，不能当作已确认追溯链。

## 数据清洗的关键约定

- 保留原文件与原值；清洗结果另存，并记录输入路径、字段映射、行数变化和排除原因。
- 时间戳核对时区、采集端时钟、秒/毫秒精度、班次跨日和迟到事件。当前用户在中国并不能证明设备原始时区；未经确认不要直接给无时区时间附加 `Asia/Shanghai`。
- 单位换算保留原单位和目标单位。压力同时核对绝压/表压；流量同时核对标准状态和气体。无法确定时分组展示，不合并。
- 去重必须依据业务键与事件身份。相同时间和值可能是不同炉管、不同温区或有效重复采样；累计计数器还可能复位、回卷或更换设备。
- 缺失值、通信中断和无效质量码不等于 0。过程曲线填补须保留标记；状态区间、产量和报警记录不能靠插值补造事件。
- 分类字段保留原始状态码；未知状态单独统计覆盖率，不自动归到运行或故障。

常见量纲检查：

| 量 | 处理约定 |
|---|---|
| 压力 | `1 mbar = 100 Pa`；Torr 与 mTorr 不相同。先区分氧化步骤和沉积步骤，再判断差异 |
| 气体流量 | `1 SLM = 1000 sccm` 仅在相同标准状态定义下适用；记录各设备的标准状态定义 |
| 温度 | 区分 ℃ 与 K，区分炉温、片温、设定值与实测值 |
| 膜厚/寿命 | nm 与 µm、µs 与 ms 分别统一；保留方法、测量位置及工序 |
| 比率 | 明确 0–1 或 0–100%；效率变化标注相对百分比或绝对百分点 |
| 电性能 | Voc 的 mV/V、Isc 的 A 与 Jsc 的 mA/cm²、接触电阻率与电阻不得直接互换 |

原文对压力与流量有需核实的表述，不能用数量级检查擅自修订，见[缺口清单](../knowledge/gaps-and-conflicts.md)。

## 批量设备与 OEE

原资料没有定义工厂的 OEE、运行状态映射、计划生产时间或理想节拍。执行 OEE 任务时先写清计算契约：

1. 统计粒度是整机、炉管、工序、产线还是班次；多炉管如何汇总。
2. 统计窗口、班次日历、计划停机扣除规则、边界区间和末次状态的截止方式。
3. 状态优先级和互斥规则，报警、清洗、待料、换舟及维护如何归类。
4. 产量是投入、完成、过站还是最终合格；返工、重测、报废、在制如何处理。
5. 性能分母采用按配方/规格的理想周期、理想片速还是其他已批准定义；实际载片量如何计入。
6. 各因子的公式、数据来源、计量单位、零分母处理及规则版本。

若项目已有 `OEE = A × P × Q` 定义，分别核对 A、P、Q 的分母和聚合规则，不能只因公式相同就认为口径一致。未有现场定义时，可以展示原始状态覆盖、区间时长、产量分布、周期分布和候选公式演算；演算明确标为“假设口径”，不输出“正式 OEE”。

推荐以半开区间 `[start, end)` 切分状态与跨班事件，属于本知识库的实现建议；若既有系统有其他边界约定，先兼容其明确规则。报警持续时间不自动等于停机时间，多报警重叠也不能重复累加。

## 工艺与质量分析

按路线、工序、配方版本、炉管、温区、舟位置和材料批次分层后比较。批量炉同时观察升温、稳定、反应、降温、装卸阶段；整体周期异常不能直接判为反应时间异常。[15 一/1.6](../references/kd/15_tube_furnace_equipment.md)提供了分阶段参考，但并非现场状态机。

温度、气流、压力与最终 Voc、FF、J₀ 等的关联只能作为排查线索。先检查材料、设备维护、测量条件和配方变化，再提出待验证原因，不能以相关性给出根因结论。

比较电池/组件效率时保留器件类型、测试面积和测试条件。[13 第1–2节](../references/kd/13_cell_testing_characterization.md)给出 STC 和 I-V 指标解释；实验室纪录、量产均值和组件效率分别展示。

## 交付与未知字段处理

交付应能复算：输入及时间范围、实际粒度、字段/单位映射、清洗摘要、公式/规则版本、结果和证据、限制及下一步。图表轴必须有单位；统计应给样本数、有效覆盖率和排除项。

没有数据字典时仍可完成文件结构检查、字段类型/取值/缺失率概览、候选键检验、重复/时间顺序/计数器问题定位及按原单位分组的描述统计。只把影响结论的缺口作为针对性问题提出；不要因缺少正式口径而停止可独立完成的数据检查。

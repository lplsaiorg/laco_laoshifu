## 概述：四类管式设备在光伏工艺中的位置

```
N型硅片（TOPCon工艺）
    │
    ├─ 制绒 + 清洗
    │
    ├─①【管式硼扩散炉】── BCl₃/BBr₃ 气体源 ──► P+ 硼发射极（前侧）
    │       温度 >1000°C，低压 300 mbar
    │
    ├─②【管式干氧氧化炉】── O₂/H₂O干湿氧 ──► SiOₓ 隧穿层（~1.5 nm，背面）
    │       温度 850~1000°C
    │
    ├─③【管式 LPCVD】─── SiH₄ 热分解 ────► poly-Si 沉积（背面，~100~200 nm）
    │       温度 580~620°C，真空 10~110 Pa
    │       ↓ 非原位磷扩散（POCl₃，850~950°C）
    │
    └─④【管式 PECVD】─── SiH₄/NH₃ 等离子 ─► SiNₓ:H ARC（正背面）
                                         或 SiOₓ + poly-Si 三合一（PECVD路线）
            温度 350~500°C，RF/微波激发
```

**同一"管式"物理形态，四炉对应不同物理/化学过程**：

| 设备 | 核心过程 | 工作温度 | 气氛 | 主要产物 |
|------|---------|---------|------|---------|
| 管式硼扩散炉 | 气固扩散（B→Si） | >1000°C | BCl₃/BBr₃+O₂+N₂ | P+ 发射极 |
| 管式干氧氧化炉 | 热生长 SiO₂ | 850~1000°C | 干 O₂（或湿氧/HCl） | ~1.5 nm SiOₓ 隧穿层 |
| 管式 LPCVD | 低压 CVD（SiH₄ 热分解） | 580~635°C | SiH₄(+PH₃)+N₂，真空 | poly-Si 薄膜 |
| 管式 PECVD | 等离子增强 CVD | 350~500°C | SiH₄+NH₃(+N₂O)，RF | SiNₓ:H / a-Si:H |

## 一、管式硼扩散炉

### 1.1 工艺背景

TOPCon 电池以 N 型硅为衬底，正面需要 **P+ 硼掺杂发射极**，对应"管式硼扩散炉"。与 P 型电池的磷扩散炉物理结构相近，但气体系统、温度、工艺配方完全不同。

### 1.2 设备结构

```
【管式硼扩散炉截面示意】

          ┌─────────────────────────────────────┐
          │            石英炉管（φ380~450mm）     │
          │  ┌─────────────────────────────┐    │
          │  │  石英舟（Boat）              │    │
          │  │  ┃片 ┃片 ┃片 ┃…片…┃片 ┃    │    │
          │  └─────────────────────────────┘    │
          │         ↑↑ 工艺气体流向 ↑↑           │
          └─────────────────────────────────────┘
          外部加热元件（SiC 电阻加热棒，多温区）
          ◄── 推拉桨（Paddle），自动进出片 ──►
```

**主要组成部件：**

| 部件 | 材质/规格 | 功能 |
|------|---------|------|
| 石英炉管 | 高纯石英，φ380~450 mm，L~2.5 m | 反应腔体，高温气密 |
| 石英舟 | 高纯石英 / SiC 涂层 | 承载硅片（立式插片），片间等距 |
| 加热元件 | SiC 电阻棒 / 红外辐射管 | 多温区独立控制（5~6区） |
| 推拉桨（Paddle） | 石英/SiC | 自动将石英舟送入/抽出炉管 |
| 气体管路 | 不锈钢（防腐） | 通入 BCl₃/BBr₃、O₂、N₂ |
| 尾气处理 | 碱液洗涤塔 / 活性炭吸附 | 中和 BCl₃/HCl/Cl₂ 尾气 |
| 真空系统（低压版） | 干式真空泵 | 低压扩散（300 mbar） |

### 1.3 扩散气体源：BCl₃ vs BBr₃

| | BCl₃（三氯化硼） | BBr₃（三溴化硼） |
|-|---------|---------|
| **物理状态** | 气态（瓶装供气） | 液态（需鼓泡装置，N₂携带） |
| **BSG 去除** | 容易（Cl 基 BSG 较松散） | 较难（副产物易粘附石英） |
| **石英管清洁** | 含 Cl，自清洁效果，gettering | 副产物粘附，停机清洗频率高 |
| **腐蚀性** | 强（HCl 副产物，需防腐管路） | 中等 |
| **安全管理** | 气瓶直接使用，无鼓泡装置 | 需防液体泄露 |
| **市场占比（趋势）** | 增长中（Semco、拉普拉斯、SC新能源推荐） | 传统主流，占比下降 |

### 1.4 工艺流程与参数

```
硅片装舟（立式，片间~3~4 mm 间距）
    ↓ 推桨进炉（速度 5~50 mm/min，缓慢避免热冲击）
    ↓ 升温至工艺温度（>1000°C，分段升温）
    ↓ 预沉积（Pre-deposition）：通入 BCl₃ + O₂ + N₂
    │     反应：4BCl₃ + 3O₂ → 2B₂O₃ + 6Cl₂
    │     B₂O₃ 沉积在硅片表面形成 BSG（硼硅玻璃）
    ↓ 驱入（Drive-in）：关闭 BCl₃，通纯 N₂（或 O₂），高温保温
    │     B 原子从 BSG 扩散进入 Si 晶格
    │     氧化性气氛有助于控制发射极深度和表面浓度
    ↓ 降温出炉（缓慢降温，避免热应力）
    ↓ 卸舟，硅片送入 BSG 去除（稀 HF 浸泡 1~2 min）
```

**关键工艺参数：**

| 参数 | 典型值 | 作用 |
|------|------|------|
| 扩散温度 | **>1000°C**（常用 1000~1050°C） | B 在 Si 中扩散系数随温度急增 |
| 工艺压力 | **300 mbar**（低压，LPD） | 均匀性优于常压，片间浓度一致 |
| O₂ 流量 | 关键变量（≫ BCl₃ 流量的影响） | 控制 BSG 厚度和发射极钝化质量 |
| BCl₃ 流量 | 次要变量 | 影响 BSG 中 B 浓度 |
| 整体周期 | **~150 min**（vs 磷扩散 ~102 min） | 硼扩散系数低，需更长时间 |
| 目标方块电阻（均匀发射极） | **70~100 Ω/sq** | 平衡低复合与低接触电阻 |
| 选择性发射极（SE）重掺区 | **~75 Ω/sq**（接触区） | 激光 SE 后局部重掺 |
| 选择性发射极（SE）轻掺区 | **~230 Ω/sq**（非接触区） | 降低复合，提升 Voc |
| BSG 厚度 | **>50 nm，最佳 ~100 nm** | 后续工艺中保护发射极 |
| 载片量 | 400~600 片/管（立式石英舟） | 批量生产 |

### 1.5 工艺特殊挑战

- **高温腐蚀**：BCl₃ 在高温分解产生 HCl/Cl₂，腐蚀金属法兰和气体管路，需全 SiC/石英/耐腐材料构建高温段
- **B 扩散系数低**：B 比 P 在 Si 中的扩散系数小约一个数量级，因此温度更高、时间更长
- **发射极均匀性**：M10/G12 大尺寸硅片对炉管内温场和气流均匀性要求更高
- **BSG 残留**：BSG 必须在后续 AlOₓ 钝化前彻底去除，否则影响界面质量

### 1.6 完整工艺温度-时间曲线

典型 BCl₃ 硼扩散完整周期各阶段（总时长 ~150 min）：

| 阶段 | 温度 | 时间 | 气体 | 作用 |
|------|------|------|------|------|
| 进舟（Push-in） | 室温→800°C | ~20 min | N₂ 保护 | 缓慢进炉，避免温度冲击碎片 |
| 升温稳定 | 800→1000°C | ~15 min | N₂ | 多温区独立升温，等待 ±0.5°C 稳定 |
| 预沉积（Pre-Dep） | **1000~1050°C** | **15~20 min** | BCl₃ + O₂ + N₂ | BSG 层形成（~100 nm），B 源注入表面 |
| 驱入（Drive-in） | **1000~1050°C** | **40~60 min** | N₂（或微量 O₂） | B 从 BSG 向 Si 体内热扩散，方块电阻均匀化 |
| 炉内补充氧化（可选） | 1000~1050°C | 0~10 min | O₂ | SiO₂ 盖层形成，阻止 B 向外逸散，改善 BSG 膜质 |
| 降温 | 1000→800°C | ~20 min | N₂ | 减小热应力，防止硅片翘曲 |
| 出舟（Pull-out） | 800°C→室温 | ~15 min | N₂ | 缓慢取出，自然冷却 |

> **BCl₃ 的 Gettering 效应**：BCl₃ 热分解产生的 Cl₂/HCl 在高温下能与硅体内的金属杂质（Fe、Cu、Ni 等）形成挥发性氯化物（如 FeCl₂、CuCl）排出，清洁硅晶格，提升少子寿命约 10~30%。这是 BCl₃ 相比 BBr₃ 在产业端推广的重要附加优势。

### 1.7 BSG 深层作用机制

BSG（硼硅玻璃，Borosilicate Glass）在工艺中具有多重功能：

**① 硼源储存库（Drive-in 阶段）**
- BSG 中 B 浓度梯度驱动 B 持续向 Si 体内扩散
- BSG 厚度 >5 nm 即可保证 Drive-in 中 B 的稳定供应
- BBr₃ 二次沉积技术：在 BSG 形成后再追加一次 BBr₃ 预沉积，可额外提升 BSG 硼含量，将方块电阻降低 ~10 Ω/sq

**② 表面浓度调控**
- Drive-in 中通入少量 O₂ 可在 BSG/Si 界面形成 SiO₂ 阻挡层，降低 B 向 Si 的传输系数
- 通过 O₂ 流量精确控制表面峰值 B 浓度（Ns），调整 Emitter 轮廓

**③ 后工序物理保护**
- BSG 厚度 ≥50 nm（最佳 ~100 nm）时，可保护发射极在 KOH 去绕镀步骤中不被蚀刻
- BSG 去除时机：在 AlOₓ ALD 钝化前，用稀 HF（1~2%）浸泡 1~2 min 精确去除（HF 对 BSG 刻蚀速率 ~20 nm/min）

### 1.8 选择性发射极（SE）激光掺杂工艺

**设计目标**：金属接触区重掺（低接触电阻）+ 非接触区轻掺（低复合），差异化提效：

| 区域 | 方块电阻 | 设计目标 |
|------|---------|---------|
| 金属接触区（p⁺⁺，SE 重掺区） | **50~75 Ω/sq** | 降低接触电阻，减小 FF 损失 |
| 非接触区（p⁺，普通发射极） | **180~230 Ω/sq** | 降低表面复合，提升 Voc |

**绿光激光（532 nm）SE 实现路径**：
```
步骤①：BCl₃ 扩散 → 均匀轻掺发射极（~230 Ω/sq）+ BSG 保留
步骤②：绿光激光扫描栅线区 → 激光熔融 BSG，B 局部快速注入 Si（→ ~75 Ω/sq）
步骤③：HF 去除全部 BSG → 双区发射极裸露
步骤④：AlOₓ（ALD）+ SiNₓ（PECVD）钝化
步骤⑤：丝网印刷对位 → 金属栅线精准落在激光重掺区
```

- **效率提升**：SE 工艺可带来 **+0.1~0.2% 绝对效率**（Voc +2 mV，FF +0.2%）
- **激光参数优化**：功率 ~80%、速度 500 mm/s 时，局部方块电阻从 230 降至 75 Ω/sq，复合电流 J₀ 从 45.3 降至 31.1 fA/cm²

## 二、管式干氧氧化炉

### 2.1 工艺背景

TOPCon 背面结构的核心是 **超薄 SiOₓ 隧穿层（~1.5 nm）**。管式干氧氧化炉通过高温 O₂ 氧化 Si 表面，生长致密高质量 SiO₂。这是 LPCVD 路线中制备 SiOₓ 的主要方法之一（也可在 LPCVD 炉管内完成，形成"LPCVD 氧化"）。

### 2.2 设备结构

物理结构与扩散炉相近，区别在于：
- **气体系统**：通入高纯干燥 O₂（无水汽）
- **温度范围**：850~1000°C（氧化温度）
- **部分设备带 HCl**（三氯乙烯，TCA）：氯氧化（Cl-oxidation）可吸收金属杂质（gettering 效果）

### 2.3 干氧 vs 湿氧 vs 湿化学氧化

| 方法 | 气氛 | 氧化速率 | 膜质 | 厚度控制 | 设备 |
|------|------|---------|------|---------|------|
| **干氧（Dry O₂）** | 纯 O₂ | 慢 | **致密，高质量** | 精确，自限制趋势 | 管式炉 |
| **湿氧（Wet O₂ / H₂O+O₂）** | O₂+H₂O 蒸汽 | 快（约10倍） | 较疏松 | 较难控制超薄 | 管式炉 |
| **湿化学氧化（HNO₃/O₃）** | 液相 | 快，自限制 | 良好 | ~1.5 nm 自停 | 湿法工作台 |
| **等离子氧化** | 等离子 O₂ | 慢，可控 | 良好 | ~1~2 nm | PECVD 炉管 |

> **TOPCon 量产选择**：湿化学氧化（HNO₃/O₃）因其低成本批量处理特性成为主流；管式干氧热氧化因膜质致密是高效电池验证首选；两者均可与 LPCVD 集成（先氧化，再通 SiH₄ 沉积 poly-Si）。

### 2.4 工艺参数

```
【典型 LPCVD 设备内集成干氧氧化工艺步骤】

N₂ 冲洗 × 3（置换管内残余气体）
    ↓ 检漏（≤ 1 Pa/min 压升率）
    ↓ 升温至 585~625°C
    ↓ 抽真空至 110 Torr（工作压力）
    ↓ 通入 O₂，恒温保压 15~25 min
    │     Si 表面氧化：Si + O₂ → SiO₂
    │     目标厚度：~1.5 nm
    ↓ 关闭 O₂，N₂ 吹扫（去除残余 O₂）
    ↓ 直接切换至 SiH₄ 进行 poly-Si 沉积（"二合一"）
```

**关键工艺参数：**

| 参数 | 典型值 | 说明 |
|------|------|------|
| 氧化温度 | **585~625°C**（低温）/ 850~1000°C（高温热氧化） | 低温与 LPCVD poly-Si 集成；高温单独成炉 |
| 氧化压力（低温） | **110 Torr** | LPCVD 集成工艺条件 |
| O₂ 流量 | 5 L/min（典型） | 流量影响氧化速率均匀性 |
| N₂ 保护流量 | 12 L/min | 稀释 O₂，防止过氧化 |
| 氧化时间 | 15~25 min | 超薄层生长，需精确控时 |
| 目标厚度 | **1.4~1.8 nm**（中心 ~1.5 nm） | 过薄隧穿效果差，过厚阻挡载流子传输 |
| 温度均匀性要求 | **±1°C**（恒温区） | 厚度均匀性直接影响电池性能 |

### 2.5 隧穿层厚度控制的重要性

```
SiOₓ 厚度 < 1.0 nm → 钝化质量差，界面态高，Voc 低
SiOₓ 厚度 1.4~1.8 nm → 最佳区间：隧穿导通 + 充分钝化
SiOₓ 厚度 > 2.5 nm → 电子隧穿受阻，串联电阻上升，FF 下降
```

### 2.6 Deal-Grove 氧化动力学模型

Deal-Grove 模型（1965年，B.E. Deal & A.S. Grove，Stanford/Fairchild）是描述热氧化速率的理论基础，指导工程控制氧化层厚度。

**三步传输机制**：
```
① 氧化剂（O₂ / H₂O）从气相扩散至 SiO₂ 表面
② 氧化剂通过已有 SiO₂ 层向 Si/SiO₂ 界面扩散（限速步骤）
③ 氧化剂与 Si 在界面反应：Si + O₂ → SiO₂（或 Si + 2H₂O → SiO₂ + 2H₂）
```

**生长速率解析方程**：

$$X^2 + AX = B(t + \tau)$$

其中：X 为氧化层厚度，t 为时间，τ 为初始氧化层等效时间，B 为抛物线速率常数，B/A 为线性速率常数。

| 极限区间 | 条件 | 增长规律 | 控制因素 |
|---------|------|---------|---------|
| **线性区**（短时） | t ≪ A²/4B | X ≈ (B/A)·t | 界面化学反应速率（新鲜 Si 暴露时） |
| **抛物线区**（长时） | t ≫ A²/4B | X ≈ √(B·t) | O₂/H₂O 通过 SiO₂ 层的扩散 |

**干氧 vs 湿氧速率常数（1000°C 典型值）**：

| 参数 | 干氧 | 湿氧 |
|------|------|------|
| 线性速率常数 B/A（nm/min） | ~6.2 | ~200 |
| 抛物线速率常数 B（nm²/min） | ~660 | ~3600 |
| 速率对比（湿/干） | 1× | **约 5~10 倍快** |
| 活化能（扩散限速，B） | ~1.24 eV | ~0.78 eV |

> **TOPCon 超薄层的特殊性**：Deal-Grove 模型在氧化层 <35 nm 时精度下降（存在"快速初始氧化"区域，真实速率比模型预测快）。~1.5 nm 的隧穿层生长完全在线性区，且受到表面清洁度、硅晶向（(100) vs (111)）等因素影响，**工程控制依赖实验标定曲线而非纯粹理论**。

### 2.7 氯氧化工艺（Cl-Oxidation）

在干氧 O₂ 中加入 **1~3% HCl**（或等效 TCA：三氯乙烷 / TCE：三氯乙烯）进行氯氧化，具备多重工艺优势：

| 效果 | 机理 |
|------|------|
| **提升氧化速率 10~15%** | Cl 与 Si 形成 Si-Cl 键，催化 O₂ 与 Si 的界面反应 |
| **降低界面态密度（Dit）** | Cl 在 Si/SiO₂ 界面形成 Si-Cl-O 复合体，中和界面悬挂键，减少缺陷态 |
| **钝化可动离子（Na⁺, K⁺）** | 生成挥发性 NaCl/KCl 排出，或将离子固定在 SiO₂ 中，防止 MOS 器件阈值漂移 |
| **Gettering 金属杂质** | 高温下 Cl 与 Fe、Cu、Ni 等形成挥发性金属氯化物逸出 |
| **提高 SiO₂ 击穿强度** | 界面缺陷密度降低，氧化层结构更致密均匀 |

**RTO（快速热氧化）补充**：
- 红外辐射快速升温（~100°C/s），在 800~1100°C 短时完成氧化（10~60 s）
- 加 HCl 可使界面态密度降至 **Dit < 1×10¹⁰ cm⁻²·eV⁻¹**（接近理论极限）
- 在 TOPCon 研发阶段常用 RTO 制备隧穿层（薄膜质量接近 ALD），量产中主要使用管式炉热氧化

### 3.5 绕镀（Wrap-Around）问题

**绕镀成因**：LPCVD 沉积无方向性，SiOₓ 和 poly-Si 薄膜会同时覆盖硅片正面、侧面和背面。

```
绕镀示意：
         ←── 正面（预期无 poly-Si）──►
  ─────────────────────────────────────────
  poly-Si（绕镀）│  N 型 c-Si 衬底  │poly-Si（目标）
  SiOₓ（绕镀）  │                  │SiOₓ（目标）
  ─────────────────────────────────────────
                    ↑ 侧面也有绕镀
```

**去绕镀三步湿法工艺：**

```
步骤①：HF 酸单面清洗（正面 + 侧面）
        → 去除 PSG（磷硅玻璃，磷扩后表面氧化物）
        → 速率差：HF 对 PSG > HF 对 poly-Si

步骤②：KOH 碱液双面清洗（刻蚀正面绕镀 poly-Si）
        → KOH 刻蚀掺杂 poly-Si：604 nm/min
        → KOH 刻蚀 PSG（背面保护层）：210 nm/min
        ⚠ 时间窗口极窄：PSG 保护背面 poly-Si，
           但一旦背面 PSG 消耗完，背面 poly-Si 也被刻蚀！
        → 控制难点：两个速率差约 3:1，精确控制时间

步骤③：HF 酸双面清洗
        → 去除正面绕镀 SiOₓ + 背面剩余 PSG
```

**去绕镀替代方案（改善控制精度）：**

| 方案 | 说明 | 优势 |
|------|------|------|
| **N₂ 退火保护氧化层**（batch 工艺） | 利用 N₂ 退火步骤在背面 poly-Si 上生成薄 SiOₓ 保护层，再进行 KOH 刻蚀 | 保护层更稳定，时间窗口更宽 |
| **水平插片（拉普拉斯专利）** | 硅片水平放置，减少侧面和正面绕镀量，绕镀控制在 10 mm 内 | 从源头减少绕镀 |
| **大气干法刻蚀（ADE）** | 分子氟（F₂）气相单侧刻蚀 poly-Si | 速率高 10 倍，无废液，选择性好 |
| **PECVD 路线替代** | 改用 PECVD，绕镀仅 2 mm | 根本减少绕镀，但牺牲均匀性 |

### 3.7 安全管理：SiH₄（硅烷）

SiH₄ 是 LPCVD 的核心气体，**极易燃、可自燃**，是最危险的工艺气体之一：

| 危险属性 | 数据 |
|---------|------|
| 爆炸下限（LEL） | 1.4 vol%（空气中） |
| 自燃下限（SFTL） | 2.5 vol%（N₂ 中） |
| 自燃范围 | **1~3 vol%**（低浓度自燃，无需点火源！） |
| OSHA 允许暴露限值 | 0.5 ppm（皮肤/吸入）|

**KL1200 安全设计（以 5 管系统为例）：**
- 极限条件下 SiH₄ 最高浓度：**0.398 vol%**（远低于 LEL）
- 真空泵 N₂ 吹扫：本体 40 SLM + 尾排稀释 60 SLM，共 100 SLM
- 尾气处理：燃烧塔（Burn Box）+ 湿式洗涤塔，确保排放达标

### 3.8 poly-Si 微结构演化与相变机制

SiH₄ 热分解沉积的 Si 膜微结构，随温度不同呈现三种形态：

| 沉积温度 | 沉积态微结构 | 退火后微结构 | 钝化接触 J₀ |
|---------|----------|------------|-----------|
| < 570°C | 纯非晶（a-Si） | 需长时退火（>900°C, >60 min）才能完全晶化 | 偏高（晶化不均匀） |
| **575~600°C** | **准非晶 / 混合相** | **900°C × 60 min → 均匀等轴晶（10~50 nm）** | **最优（~1.5 fA/cm²）** |
| 605~620°C | 直接多晶（柱状晶，从 SiOₓ 界面向上生长） | 保持柱状晶结构 | 略差（柱状晶界多） |
| > 640°C | 粗糙多晶，沉积速率快但均匀性差 | 粗晶界，缺陷密度高 | 差 |

> **量产推荐路径**：580~600°C 沉积（接近非晶），利用后续 **磷扩散退火（850~900°C）** 统一晶化——"先沉积后晶化"路线。晶粒成核点多且均匀，J₀ 最低，是目前 TOPCon 量产主流选择。

**退火参数对钝化质量的影响**：
- 退火 900°C × 60 min：J₀ = **1.49 fA/cm²**（最优）
- 退火不足（<800°C）：非晶残余，缺陷密度高，J₀ > 10 fA/cm²
- 退火过度（>1000°C）：P 向 c-Si 衬底过深扩散（>5 nm），隧穿层电场效应削弱，J₀ 反升

### 3.9 氢气泡（Blistering）产生机制与抑制策略

气泡是 PECVD 路线 poly-Si 的主要失效模式，LPCVD 天然免疫此问题：

**根本原因对比**：
```
LPCVD（~600°C 热分解）：
  SiH₄ 热能充足 → Si-H 键立即断裂 → H₂ 直接逸出气相
  沉积膜 Si-H 键浓度 ≈ 0 → 退火后无 H₂ 气体积累 → 无气泡 ✓

PECVD（~400°C 等离子活化）：
  等离子体能量低于热能 → Si-H 键大量保留在薄膜内
  退火升温 → Si-H 断裂 → H₂ 分子在 SiOₓ/poly-Si 界面积累
  H₂ 压力超过临界值（~100 MPa）→ 薄膜鼓泡/局部脱层 ✗
```

**PECVD 路线的气泡抑制策略**：

| 方法 | 原理 | 效果 |
|------|------|------|
| 升高沉积温度（400→500°C） | 减少 Si-H 键截留量 | 气泡频率显著降低 |
| **双层 poly-Si（i 层 + n 层）** | 先沉积低 H 的本征层（i），再沉积掺杂层（n） | 主流工业方案 |
| 粗糙化 SiOₓ 表面 | 增加机械锚定点，提高 poly-Si 附着强度 | 临界压力提升约 2× |
| 低氢稀释比沉积 | 减少前驱体中 H 含量 | 适当有效 |
| 500°C 预退火（30 min）→ 再升温退火 | 温和脱氢，避免 H₂ 在界面突然积累 | 消除气泡，但增加工序 |

### 3.10 钝化接触核心特征参数（J₀ 与 ρc）

**两大表征指标**：

| 参数 | 符号 | 优秀值（LPCVD 量产） | 物理含义 |
|------|------|------|---------|
| 钝化接触区复合电流密度 | **J₀ (fA/cm²)** | **≤ 1.5 fA/cm²** | SiOₓ/poly-Si 界面钝化质量，越小 Voc 越高 |
| 接触电阻率 | **ρc (mΩ·cm²)** | **1.8~2.0 mΩ·cm²** | 电流传输效率，越小 FF 越高 |

**J₀ 对 Voc 的量化影响**（典型 TOPCon 参数下）：
- J₀ 每降低 1 fA/cm² → Voc 提升约 **5~8 mV**
- J₀ = 1.5 fA/cm² → 对应钝化区 implied Voc > 720 mV（720 mV 为 c-Si 理论上限的 ~91%）

**原位磷掺杂（in-situ）vs 非原位 POCl₃ 扩散（ex-situ）深层对比**：

| 特性 | 原位掺杂（SiH₄ + PH₃，LPCVD） | 非原位 POCl₃ 扩散 |
|------|------|------|
| 掺杂均匀性（片间） | **±40%**（PH₃ 消耗导致浓度梯度） | **±5%**（气相扩散均匀） |
| 沉积速率 | **≈ 1/25**（PH₃ 抑制 SiH₄ 分解） | 正常（~6 nm/min） |
| 活性掺杂浓度 Nd | 1.3×10²⁰ cm⁻³（可达） | >10²⁰ cm⁻³（易控制更高） |
| 工艺复杂度 | 简单（一步完成） | 需额外扩散炉工序 |
| 晶化路径 | 原位退火晶化（同步完成） | 磷扩散退火（850°C）同步晶化 |
| 行业主流度 | 少数（PECVD 三合一路线常用） | **~70% 产线（LPCVD 主流路线）** |

## 四、管式 PECVD

### 4.1 工艺背景

管式 PECVD（Plasma-Enhanced CVD）在光伏中有两大主要应用：
1. **SiNₓ:H 减反射/钝化层**（Al-BSF / PERC / TOPCon 正面）——最主要用途
2. **TOPCon 三合一工艺**：SiOₓ 隧穿层 + poly-Si + 原位磷掺杂（捷佳伟创 PE-Poly 路线）

| | 管式 PECVD | 板式 PECVD（inline）|

| 维护成本 | 低 | 高 |
| 占地面积 | **小** | 大 |
| 产能 | 中（受装片量限制） | 高 |
| 薄膜致密性 | **优** | 良 |
| 钝化效果 | **优** | 良 |
| HJT 适用 | **首选（捷佳伟创首创）** | 可用 |

### 4.3 SiNₓ:H 减反射层沉积工艺

**化学反应：**
```
SiH₄ + NH₃ ──[等离子体, 350~500°C]──► SiₓNᵧ:H + H₂

严格化学计量（Si₃N₄）：
3SiH₄ + 4NH₃ → Si₃N₄ + 12H₂

实际沉积：非化学计量 SiₓNᵧ:H，含大量 H
（H 原子在后续烧结时扩散入体硅，钝化晶界和体缺陷）
```

**工艺参数控制规律：**

| 参数 | 增大时的效果 |
|------|-----------|
| **NH₃/SiH₄ 比**（主要变量） | 折射率↓、沉积速率↓、应力趋拉伸↑ |
| **温度** | 沉积速率↓、均匀性↑、应力↓ |
| **RF 功率** | 沉积速率↑、折射率↓、均匀性↓ |
| **压力** | 沉积速率↑、折射率↑、均匀性↑ |

**典型工艺配方（工业 ARC 层，折射率 n=2.0~2.1）：**

| 参数 | 典型值 |
|------|------|
| 沉积温度 | **380~450°C** |
| SiH₄ 流量 | ~40 sccm（参考） |
| NH₃ 流量 | ~55 sccm（NH₃/SiH₄ ≈ 1.4） |
| 工作压力 | ~900 mTorr（120 Pa） |
| RF 频率 | 13.56 MHz（高频 HF） |
| 沉积速率 | **11~13 nm/min** |
| 目标折射率（n，633nm） | **2.00~2.10** |
| 目标膜厚 | **75~80 nm** |
| 颜色（视觉） | 蓝色（最小反射波长 ~600 nm） |

**折射率对应关系：**

| 折射率 n | 含义 |
|---------|------|
| n < 1.9 | 氮过多，类 Si₃N₄，绝缘性强，H 含量高 |
| n = 2.0~2.1 | **最优 ARC 区间**，兼顾减反射和钝化 |
| n > 2.3 | 硅过多，导电性增强，Si-Si 键多 |

### 4.4 TOPCon 三合一工艺（管式 PECVD 路线）

捷佳伟创 PE-Poly 方案，在单台管式 PECVD 内完成三个步骤：

```
步骤①：SiOₓ 隧穿层沉积（等离子氧化）
        气氛：N₂O（或 O₂）+ 等离子体
        温度：低温（<500°C）
        目标：~1.5 nm SiOₓ
        ⚠ 缺点：均匀性弱于干氧热氧化，是 PECVD 路线效率离散度高的根源

步骤②：本征 poly-Si 沉积
        气氛：SiH₄ + H₂（+N₂）
        温度：~400°C（低于 LPCVD 的 600°C）
        结构：接近非晶（需后续退火晶化，或在步骤③中一并高温退火）

步骤③：原位 P 掺杂 poly-Si 沉积
        气氛：SiH₄ + PH₃
        原位掺杂时间：LPCVD 路线的 **1/5**（速度更快）
        ⚠ 副作用：PH₃ 导致陶瓷环导电，缩短石墨舟维护周期；PH₃ 消耗过高
```

**三合一优势与局限：**

| | LPCVD + POCl₃ 扩散 | PECVD 三合一 |
|-|------|------|
| SiOₓ 均匀性 | **优**（热氧化，干净均匀） | 差（PECVD，均匀性差导致效率离散）|
| 设备台数 | 多（LPCVD + 扩散炉） | **少（三合一减少设备台数）** |
| 绕镀 | 严重（完整绕镀，~10 mm 控制后）| **轻微（边缘 2 mm 内）** |
| 原位掺杂速度 | 慢 | **快（1/5 时间）** |
| 量产效率 | 24.9%（GW级验证） | 待 GW 级充分验证 |
| 良率 | ~97% | 待验证 |

### 4.5 PECVD 在 HJT 中的应用

管式 PECVD 是 HJT（异质结）电池的必选工艺：

| 步骤 | 沉积层 | 工艺条件 |
|------|------|---------|
| 正面 i 层 | 本征 a-Si:H（~5~8 nm） | SiH₄ + H₂，<200°C，RF-PECVD |
| 正面 p 层 | p-a-Si:H（~5~10 nm，B₂H₆掺） | SiH₄ + B₂H₆ + H₂，<200°C |
| 背面 i 层 | 本征 a-Si:H | 同上 |
| 背面 n 层 | n-a-Si:H（~5~10 nm，PH₃掺） | SiH₄ + PH₃ + H₂，<200°C |

**HJT PECVD 特殊要求：**
- 全程 **< 200°C**（保护非晶硅氢化态，高温导致 H 脱附晶化）
- 极低缺陷密度 a-Si:H（本征层 ~10¹⁰ cm⁻³ 缺陷）
- 防止 p 层和 n 层之间的交叉污染（需严格腔室隔离或专用腔）

### 4.6 等离子体激发机制（RF 容性耦合 CCP）

管式 PECVD 普遍采用 **射频容性耦合等离子体（RF-CCP，13.56 MHz）**：

**放电物理过程**：
```
RF 电源（13.56 MHz）→ 内置同轴电极（梳状排列于石英舟间）
  ↓ 交变电场加速自由电子
  ↓ 高能电子碰撞气体分子（电离 + 激发）
SiH₄ → •SiH₃ + H•    （硅基自由基，主要成膜物种）
NH₃  → •NH₂ + H•      （氨基自由基）
N₂   → N₂*（激发态，辅助反应）
  ↓ 活性基团扩散至硅片表面吸附 → SiNₓ:H 薄膜生长
```

**频率选择的影响**：

| 频率 | 类型 | 特点 |
|------|------|------|
| **13.56 MHz（HF）** | 容性耦合（CCP），直接等离子体 | 工业主流，离子轰击能量适中，沉积速率高 |
| **40~60 MHz（VHF）** | 容性耦合，高频 | 电子密度更高，均匀性更好，适合大面积 |
| **2.45 GHz（微波）** | 远程等离子体 | 中性活性基团为主，离子损伤极小，HJT 本征层适用 |

**管式 PECVD 的"梳状"电极优势**：
- 电极与硅片交替排列，每两片间均形成均匀等离子体
- 相比平板式，等离子体均匀性更高（片间 ≤4%）
- 腔体容积利用率高（同尺寸管内可装更多片）

### 4.7 SiNₓ:H 双重钝化机制（深层解析）

SiNₓ:H 通过两种独立机制钝化 Si 表面，两者同时作用：

**① 化学钝化（Chemical Passivation）**
- 核心：H 原子扩散至 Si/SiNₓ 界面，饱和悬挂键：**Si• + H → Si-H**
- 量化指标：界面态密度 **Dit（cm⁻²·eV⁻¹）**，优秀值 Dit < 10¹⁰ cm⁻²·eV⁻¹
- 关键：H 必须以**原子态**（而非分子 H₂）扩散，才能进入 Si 晶格

**② 场效应钝化（Field-Effect Passivation）**
- 核心：SiNₓ:H 内含大量**正固定电荷 Qf**（典型值 Qf > 10¹² cm⁻²），在 Si 表面产生内建电场
  - P 型 Si 表面：正 Qf 排斥空穴，表面载流子浓度降低 → 复合速率下降
  - N 型 Si 正面：正 Qf 积累电子（同号），同样降低表面少子（空穴）浓度
- Qf 来源：Si-N 键的极性差（Si 略正）+ N 空位缺陷（带正电）

**N-rich vs Si-rich 对两种机制的影响**：

| 参数 | N-rich（NH₃/SiH₄ 比高） | 最优区间（n=2.0~2.1） | Si-rich（NH₃/SiH₄ 比低） |
|------|---------|---------|---------|
| 折射率 n | < 1.9 | **2.0~2.1** | > 2.3 |
| 薄膜致密性 | 高（类 Si₃N₄） | 适中 | 低（Si-Si 键多） |
| 固定电荷 Qf | 低 | 中 | **高** |
| H 释放形式（烧结） | **原子 H**（有效钝化） | 混合 | 分子 H₂（无效） |
| 化学钝化效果 | **优** | **优** | 差 |
| 场效应钝化效果 | 差 | 良 | **优** |
| ARC 光学匹配 | 差（折射率偏低） | **优** | 差（折射率偏高） |

> **量产推荐配方**：折射率 n = 2.0~2.1（NH₃/SiH₄ ≈ 1.0~1.4），在 ARC 光学效果、化学钝化、场效应钝化三者间取得最优平衡，也是行业"蓝色 SiNₓ 膜"的标准配方。

### 4.8 烧结（Firing）氢钝化过程

烧结是 SiNₓ:H 发挥氢钝化体缺陷的关键步骤：

**典型快速烧结参数**：峰值温度 ~800°C，峰值时间 ~3~5 秒

**氢再分布机制**：
```
烧结升温（600→800°C）
  ↓ SiNₓ:H 薄膜中 N-H 键断裂，释放原子 H
  ↓ H 原子扩散穿过 AlOₓ（PERC/TOPCon 前表面）或直接进入体硅
  ↓ H 在 c-Si 体内迁移，遇到缺陷位点：
    · 晶界悬键（Si•）+ H → Si-H     （多晶 Si 体钝化）
    · Fe-B 对、O-B 对等复合中心 + H → 钝化
    · c-Si / SiOₓ 界面（TOPCon）+ H → 界面态密度 Dit 降低
烧结冷却（800→室温，<1 s）
  ↓ H 冻结在新位置（Si-H 键稳定，室温下不再移动）
  ↓ 少子寿命提升（体硅钝化完成）
```

**TOPCon P 型 poly-Si 的特殊氢活化需求（Fraunhofer ISE 研究）**：
- P 型 poly-Si 钝化接触要求更高的 H 活化能 → 需要更高温度或更长时间
- 分段退火策略（低温预退火 500°C + 快速烧结）可在较低峰值温度下实现充分 H 扩散
- 优化后 P 型 poly-Si 钝化接触可达 **J₀ = 7.9 fA/cm²**（绒面，2024年最优报告）

**SiNₓ:H vs 形成气体退火（FGA）的氢钝化效果比较**：
- SiNₓ:H 烧结：薄膜内 H 储量大（~10²¹ cm⁻³），释放量充足，implied Voc 更高
- FGA（N₂:H₂ = 95:5，400°C）：H₂ 含量少，钝化效果弱于 SiNₓ:H

### 4.9 腔体清洗与设备维护

**In-situ 等离子体清洗（腔体自清洗）**：

| 清洗气体 | 清洗反应 | 特点 |
|---------|---------|------|
| **CF₄ + O₂**（体积比 4:1） | CF₃• 自由基刻蚀 SiNₓ 沉积物；O₂ 氧化 C 副产物 | 最常用，成本低，刻蚀速率适中 |
| **NF₃**（纯气） | NF₂• + F• 高活性自由基，刻蚀速率快 | 速率快 5~10×，但成本高，GWP 高（温室气体） |
| **SF₆ + O₂** | S/F 自由基刻蚀 Si 基沉积物 | 较少使用 |

**清洗工艺典型参数**：
- **清洗频率**：每 5~10 批（~Run）执行一次，防止累积沉积物剥落污染硅片
- **清洗温度**：400~450°C（同沉积温度，维持热平衡）
- **清洗功率**：高于沉积功率（提升等离子体密度以加快刻蚀）
- **清洗时长**：5~20 min（依 SiNₓ 累积厚度而定）
- **终点判断**：光学发射谱（OES）监测 F 原子发射峰（703.7 nm）突然增强，表示沉积物已刻蚀完毕

**石墨舟维护周期**：

| 维护项目 | 周期 / 条件 | 操作要点 |
|---------|---------|---------|
| 表面 SiNₓ 蚀刻处理 | 每 **30~50 批** | HF 酸浸泡去除表面 SiNₓ 积累，恢复表面导电性 |
| 片间均匀性验证 | 每周 | 测量舟头/中/尾参考片折射率（目标 n=2.05±0.05） |
| 腔体碎片清理 | 每 2 周 | 防止碎片阻挡热电偶、影响气流均匀性 |
| 陶瓷环/导电环检查 | 每月 | PH₃ 掺杂工艺中 PH₃ 导致陶瓷环导电，需定期更换 |
| **石墨舟全套更换** | **使用 >3 年** | 老旧舟片间均匀性退化（>6%），强制更换 |

> **石墨舟最佳状态**：新舟投入使用约 30 批后，表面 SiNₓ 预涂均匀，片间均匀性最优。此后随使用次数增加，均匀性缓慢退化，建议在均匀性超出 ±4% 规格前计划性维护。

### 5.2 工艺顺序（TOPCon 完整流程中的位置）

```
N型硅片
  ↓
制绒 + RCA 清洗
  ↓
【管式干氧氧化炉 / 湿法化学氧化】── 背面 SiOₓ（1.5 nm）
  ↓
【管式 LPCVD】── 背面 poly-Si（100~200 nm）+ 非原位磷扩散
  ↓
湿法去绕镀（HF → KOH → HF，三步）
  ↓
【管式硼扩散炉】── 正面 P+ 发射极（BCl₃，>1000°C，150 min）
  ↓

  ↓
【管式 PECVD】── 正面 SiNₓ:H（减反射+钝化）+ 背面 SiNₓ（poly保护）
  ↓
丝网印刷 + 烧结 + LECO
  ↓
测试分选
```

### 5.3 深层技术知识速查

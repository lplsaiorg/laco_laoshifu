## 1. 光伏产业链材料全景

```
【上游原材料】

【电池制造材料】

```

## 2. 银浆（Silver Paste）

银浆是光伏电池制造中最昂贵的非硅材料，占非硅成本约 40%。

### 2.1 成分组成

| 组分 | 占比（wt%） | 作用 |
|------|-----------|------|
| **银粉（Ag Powder）** | 70~85% | 导电主体，形成金属栅线骨架 |
| **玻璃料（Glass Frit）** | 2~10% | 烧结过程中腐蚀 SiNₓ 并形成 Ag-Si 欧姆接触 |
| **有机载体（Organic Vehicle）** | 10~20% | 溶剂+树脂，提供流变性（印刷性） |

### 2.2 银粉特性

| 参数 | 典型值 |
|------|------|
| 颗粒尺寸 | 0.5~3 µm（微米级）/ 纳米级（特种） |
| 形貌 | 球形 / 片状（影响导电路径） |
| 纯度 | >99.9% |

### 2.3 玻璃料（Glass Frit）——关键组分

玻璃料在高温烧结过程中的作用机制：
1. **软化熔融**（~600°C）：润湿 SiNₓ 表面
2. **腐蚀穿透**：玻璃料中的 PbO（或无铅组分）腐蚀 SiNₓ 减反射层
3. **Ag 溶解传输**：Ag 溶入玻璃相，通过毛细作用传输至 Si 表面
4. **Ag 沉积析出**：Ag 在 Si 表面重结晶，形成 Ag 纳米晶粒层
5. **欧姆接触**：Ag/Si 界面形成低接触电阻

| 玻璃料类型 | 成分 | 特点 |
|---------|------|------|
| 铅硅酸盐（Pb-Si-O） | PbO + SiO₂ + 其他 | 传统，高效，活性好 |
| **无铅玻璃料** | Bi-Te-B-Si-P-O 等 | 环保趋势，效率已追平（Bi-Te基达 18.26%，接近 Pb 基 18.23%） |
| 纳米玻璃料 | 纳米级颗粒 | 接触电阻降至常规的 40%，分布更均匀 |

### 2.4 高温银浆 vs 低温银浆

| | 高温银浆（>700°C） | 低温银浆（<200°C） |
|--|---------|--------|
| 适用技术 | Al-BSF / PERC / TOPCon | **HJT**（必须） |
| 导电率 | 高（烧结致密） | 较低（导电粒子搭接） |
| 粘结机制 | 玻璃料热烧结 | 树脂热固化 / 低温焊接 |
| 单耗（g/片） | ~80~120 mg/片（PERC）| ~100~150 mg/片（HJT，更多） |
| 成本 | 基准 | **2~3 倍**（核心降本瓶颈） |

### 2.5 银浆消耗量趋势（降本驱动）

| 年份 | 单片银浆用量（PERC/TOPCon） |
|------|----------------------|
| 2018 | ~150 mg/片 |
| 2021 | ~120 mg/片 |
| 2023 | ~80~90 mg/片 |
| 2025 | ~70~80 mg/片（SMBB细栅） |
| 目标 | 铜替代 → 银耗 < 10 mg/片 |

> **多主栅（MBB）技术**是降低银耗的主要手段：汇流条由 5BB → 9BB → 16BB+，每根汇流条变细，总截面不变但银耗降低。

## 3. 铝浆（Aluminum Paste）

主要用于 Al-BSF 及 PERC 背面金属化。

| 参数 | 典型值 |
|------|------|
| Al 含量 | >70% |
| 烧结温度 | 700~850°C |
| 功能 | 与 P 型硅合金化形成 Al-BSF（铝背场） |
| 背面银铝浆 | 汇流条处加 Ag/Al 混合浆，提供可焊接区域 |

## 4. 封装胶膜（Encapsulant Film）

### 4.1 EVA（乙烯-醋酸乙烯酯）

最广泛使用的封装材料（2025年市场占比仍 >60%）。

**生产工艺**：乙烯 + 醋酸乙烯酯共聚 → 挤出流延成膜（厚度 0.3~0.5 mm）

**性能参数：**

| 参数 | 典型值 |
|------|------|
| 透光率（400~1100 nm） | >90% |
| 折射率 | ~1.49（接近玻璃，减少界面反射） |
| 体积电阻率 | >10¹⁴ Ω·cm |
| 透湿率（WVTR） | ~10 g/m²/day |
| 交联后耐温 | -40°C ~ +110°C |
| 黄变指数（YI，25年加速测试后） | < 5 |

**EVA 退化机制：**
- 醋酸乙烯酯（VA）组分水解 → 产生**醋酸（CH₃COOH）**
- 醋酸腐蚀银栅线和铝电极
- 醋酸导致 **PID（电位诱发衰减）**
- 紫外线导致 EVA 黄变，透光率下降

### 4.2 POE（聚烯烃弹性体）

**不含酯基，不产生醋酸**，是 EVA 的升级替代：

| 参数 | EVA | POE |
|------|-----|-----|
| WVTR（透湿率） | ~10 g/m²/day | ~0.1~1 g/m²/day（**低 10~100 倍**） |
| PID 抗性 | 弱 | **强（无醋酸）** |
| 热稳定性 | 一般 | 优 |
| 层压温度 | 140~150°C | 150~165°C（更高） |
| 与玻璃粘接力 | 高 | 较低（需表面处理） |
| 成本 | 基准 | +15~30% |

### 4.3 EPE（EVA/POE/EVA 三层复合）

- 前层：EVA（粘接玻璃，工艺性好）
- 中层：POE（阻水隔离）
- 后层：EVA（粘接背板）
- 兼顾工艺性和可靠性，双面/高功率组件常用

## 5. 背板（Backsheet）

### 5.1 常见结构

| 规格 | 结构 | 厚度 | 特点 |
|------|------|------|------|
| **TPT** | Tedlar/PET/Tedlar | ~350 µm | 高防潮，耐候性最佳，DuPont 原材料垄断 |
| **TPE** | Tedlar/PET/EVA | ~300 µm | 常见，成本适中 |
| **KPE/KPK** | PVDF基/PET/EVA | ~300 µm | Tedlar 替代，耐候好 |
| **APE** | 含PA尼龙/PET/EVA | ~300 µm | 成本低 |
| **CPC** | 含氟涂层/PET/含氟涂层 | ~250 µm | 轻薄，共挤 |
| **双玻（Glass）** | 钢化玻璃 2.0~3.2 mm | 2~3.2 mm | 30 年+ 寿命，重量大 |

### 5.2 关键性能

| 指标 | 要求 |
|------|------|
| WVTR（透湿率） | < 1 g/m²/day（IEC 62938） |
| 绝缘耐压 | > 1000 V（IEC 61730） |
| 热收缩率（85°C，30 min） | < 1.5% |
| 耐 UV（UVA 2000h）| 无分层、脆化 |
| 颜色 | 白色（高反射，对正面有增益）/ 黑色（BIPV美观）|

## 6. 焊带（Ribbon）与互联材料

### 6.1 常规焊带

| 参数 | 典型值 |
|------|------|
| 基材 | 无氧铜（OFC，纯度>99.9%）|
| 镀层 | Sn-Pb 合金（传统）/ Sn-Ag-Cu（无铅，RoHS）/ Sn-Bi（低温，HJT用） |
| 宽度 | 汇流条（Tab）：1~2 mm；互联带（Ribbon）：1.5~3 mm |
| 厚度 | 0.1~0.25 mm |
| 电导率 | 铜 ~5.8×10⁷ S/m |

### 6.2 圆焊带（Round Ribbon）

直径 0.3~0.4 mm 的圆形铜线替代扁焊带，搭配多主栅（MBB）：
- 圆形截面可将入射光聚焦反射回电池（光学增益）
- 减少遮光面积
- 焊接拉力相同，可靠性不降

### 6.3 导电胶（Electrically Conductive Adhesive, ECA）

HJT 和部分高端应用的无焊接互联方案：
- 低温固化（~150~180°C）
- 无热应力，适合薄片（<150 µm）
- 成本高于焊带，可靠性已验证
- 代表材料：环氧基 ECA（含 Ag 粒子）

## 7. 扩散源材料

| 材料 | 类型 | 用途 |
|------|------|------|
| **POCl₃**（三氯氧磷） | 液态磷源 | P型电池磷扩散（N+发射极），最主流 |
| **BCl₃**（三氯化硼） | 气态硼源 | N型电池硼扩散（P+发射极，TOPCon）|
| **BSG**（硼硅玻璃膜） | PECVD 固态硼源 | HJT/TOPCon 硼扩散，可控性好 |
| **TMA**（三甲基铝） | ALD 铝源 | AlOₓ 原子层沉积，PERC/TOPCon 背面钝化 |
| **SiH₄**（硅烷） | PECVD/LPCVD 硅源 | SiNₓ/a-Si:H/poly-Si 沉积 |
| **NH₃**（氨气） | PECVD 氮源 | SiNₓ:H 沉积，ARC 层 |

## 8. 清洗化学品

| 化学品 | 用途 | 浓度/温度 |
|--------|------|---------|
| **KOH/NaOH** | 单晶制绒、损伤去除 | 1~30 wt%，60~85°C |
| **HF/HNO₃ 混合** | 多晶酸液制绒 | 1~5% HF + 30~70% HNO₃ |
| **HF（氢氟酸）** | 氧化层去除（SiO₂腐蚀）| 1~5% 稀溶液 |
| **NH₄OH + H₂O₂**（SC1） | RCA 有机物清洗 | 1:1:5，70~80°C |
| **HCl + H₂O₂**（SC2） | RCA 金属离子清洗 | 1:1:6，70~80°C |
| **HNO₃/O₃** | TOPCon SiOₓ 湿化学氧化 | 65% HNO₃ 或 O₃ 水溶液 |
| **IPA（异丙醇）** | 制绒添加剂（单晶） | 1~5 vol% |

## 9. CVD/ALD 工艺气体

| 气体 | 用途 | 注意事项 |
|------|------|---------|
| **SiH₄**（硅烷） | PECVD SiNₓ/a-Si:H / LPCVD poly-Si | 极易燃，自燃危险，需专用配管 |
| **NH₃**（氨气） | PECVD SiNₓ | 有毒，需尾气处理 |
| **N₂O**（笑气） | PECVD SiOₓ | 温室气体 |
| **TMA（三甲基铝）** | ALD AlOₓ（PERC背面钝化） | 遇水剧烈反应，pyrophoric |
| **PH₃**（磷化氢） | PECVD poly-Si 原位磷掺杂 | 剧毒，1 ppm 即有危险 |
| **B₂H₆**（乙硼烷） | PECVD/LPCVD 硼掺杂 | 剧毒，需严格管控 |
| **H₂** | LPCVD 还原气氛 / HF 钝化 | 易燃易爆 |

## 11. 材料可持续性与供应链风险

| 材料 | 风险点 | 应对方向 |
|------|--------|---------|
| **银（Ag）** | 全球产量有限，光伏消耗约占全球 10%，价格波动大 | 铜电镀替代、减少单耗 |
| **铟（In）** | HJT 的 ITO 含铟，稀有金属 | AZO/ICO/ZnO:Al 替代 ITO |
| **多晶硅** | 曾被西方制裁担忧（新疆产能）| 多地分散布局 |
| **特种气体（PH₃/B₂H₆/TMA）** | 剧毒，供应链安全 | 本地化生产、应急储备 |
| **Tedlar（杜邦）** | 背板核心原材料，DuPont 供应主导 | 国产化（PVDF 替代）、双玻替代背板 |
| **钙钛矿铅（Pb）** | 环境法规压力 | 无铅钙钛矿研发 |

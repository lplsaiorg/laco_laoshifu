# 02 晶体生长

> 来源：[PVEducation - Czochralski Silicon](https://www.pveducation.org/pvcdrom/manufacturing-si-cells/czochralski-silicon)

## 1. 单晶硅——直拉法（Czochralski, CZ）

### 工艺原理
将高纯多晶硅与掺杂剂（硼 → P型，磷/镓 → N型）装入石英坩埚，加热熔化后，用籽晶（seed crystal）缓慢旋转提拉，使熔体在固液界面结晶形成单晶硅棒（Ingot）。

### 工艺参数
| 参数 | 典型值 |
|------|------|
| 提拉速度 | ~1 mm/min |
| 晶棒直径 | 200~300 mm（光伏常用 156~210 mm 方形切出） |
| 生长方向 | <100> 晶向 |
| 氧含量 | ~10¹⁸ cm⁻³（来自石英坩埚） |

### 氧与光致衰减（LID）
- 石英坩埚引入 ppm 级氧（~10¹⁸ cm⁻³）进入硅锭
- 氧本身无害，但与**硼掺杂**形成 B-O 复合物，在光照下降低少子寿命（光致衰减，LID）
- 解决方案：使用**镓（Ga）掺杂**代替硼，可消除 B-O LID；N型磷掺杂硅锭同样不受影响

### 优缺点
| | 优点 | 缺点 |
|-|------|------|
| CZ单晶 | 高少子寿命、均匀晶体结构、适合高效电池 | 成本较高、含氧量较高 |

## 2. 单晶硅——区熔法（Float Zone, FZ）

- 无坩埚，硅棒通过高频感应线圈产生的熔区缓慢移动提纯
- 氧含量极低（< 10¹⁶ cm⁻³），少子寿命极高
- 主要用于实验室高效电池研究，成本高，不适合大规模量产

---

## 3. 多晶硅——铸锭法（Multicrystalline / Casting）

### 工艺原理
将多晶硅原料装入方形石英坩埚，加热熔化后，从底部定向凝固冷却，形成柱状晶粒结构的多晶硅锭。

### 特性
| 参数 | 典型值 |
|------|------|
| 晶粒尺寸 | mm 级（可见晶界） |
| 形状 | 方形（便于切片后直接制成方形电池） |
| 少子寿命 | 低于单晶（晶界处复合较多） |
| 成本 | 低于 CZ 单晶 |

### 铸锭切砖
大型多晶硅锭切割流程：
```
方形多晶硅大锭
    ↓ 带锯（Band Saw）切割
小方砖（Brick）~156×156 mm
    ↓ 多线切割锯（Wire Saw）
硅片（Wafer）
```

## 4. 单晶与多晶对比

| 特性 | CZ 单晶 | 多晶铸锭 |
|------|---------|--------|
| 晶体结构 | 单一晶向 | 随机多晶粒 |
| 少子寿命 | 高 | 较低 |
| 制绒方式 | 碱液各向异性腐蚀（金字塔） | 酸液各向同性腐蚀或机械/等离子刻蚀 |
| 效率上限 | 更高 | 较低 |
| 成本 | 较高 | 较低 |
| 市场趋势 | 逐渐主导（PERC/TOPCon/HJT均用单晶） | 占比持续下降 |

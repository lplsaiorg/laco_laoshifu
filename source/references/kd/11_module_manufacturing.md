# 11 光伏组件封装制造工艺

> 来源：[PV-Manufacturing.org - Module Manufacturing](https://pv-manufacturing.org/solar-cell-manufacturing/pv-module-manufacturing/) | [TaiYang News](https://taiyangnews.info/technology/from-cell-strings-to-finished-modules-inside-modern-pv-module-manufacturing) | EPJ Photovoltaics 2025

---

## 1. 概述

单片太阳能电池输出功率有限、机械脆弱，无法直接用于实际应用。光伏组件（PV Module）将 **36~144 片**电池串并联封装在耐候结构中，是光伏系统的基本构建单元。

组件结构截面（从前到后）：
```
阳光
  ↓
┌───────────────────────────────┐
│    超白低铁钢化玻璃（3.2 mm）  │
├───────────────────────────────┤
│    前层封装胶膜（EVA/POE）     │
├───────────────────────────────┤
│  电池片（Cell）× N串 × M串    │
│  互联焊带连接                 │
├───────────────────────────────┤
│    后层封装胶膜（EVA/POE）     │
├───────────────────────────────┤
│    背板（Backsheet）或后玻璃  │
└───────────────────────────────┘
      铝边框（Frame）包围四周
      接线盒（Junction Box）背面中心
```

## 2. 完整工艺流程

```
电池片入库 → 来料检验（外观/IV测试）
    │
    ├─① 电池分选（Sorting / Binning）
    │       按 Isc 或 Pmax 分档，同串电池效率档位一致
    │       防止电流失配（Current Mismatch）
    │
    ├─② 焊接（Tabbing & Stringing）
    │       见第3节
    │
    ├─③ 串串检测（String EL 测试）
    │       电致发光成像，剔除裂片/虚焊/暗片
    │
    ├─④ 叠层（Layup）
    │       玻璃 → 前层胶膜 → 电池串排布 → 汇流焊接 → 后层胶膜 → 背板/后玻璃
    │
    ├─⑤ 层压（Lamination）
    │       见第4节
    │
    ├─⑥ 修边（Trimming）
    │       去除层压后溢出的多余胶膜
    │
    ├─⑦ EL 检测（层压后）
    │       复检隐裂、断栅、连片异常等缺陷
    │
    ├─⑧ 装框（Framing）
    │       铝边框四角拼接，硅酮密封胶粘合固定
    │
    ├─⑨ 接线盒安装（Junction Box）
    │       背面中心粘接，焊接引出线，充填硅酮灌封胶
    │
    ├─⑩ 组件测试（Final Testing）
    │       STC 条件 I-V 曲线（闪光仪）
    │       绝缘耐压测试（HiPot，≥1000 V + 2×Voc）
    │       IR 红外热成像（发现热斑）
    │       最终 EL 成像
    │
    └─⑪ 包装入库
```

## 3. 焊接工艺（Tabbing & Stringing）

### 3.1 焊带（Ribbon/Tab）

| 参数 | 典型值 |
|------|------|
| 材质 | 镀锡铜（Cu + Sn/Pb 或 Sn/Ag/Cu 无铅） |
| 宽度 | 1.0~2.0 mm（随汇流条数变化） |
| 厚度 | 0.1~0.25 mm |
| HJT 专用 | 低温焊带（低熔点合金，<180°C，或导电胶替代） |

### 3.2 串焊流程

```
焊带从焊带卷退出 → 助焊剂涂布
→ 自动焊接机（CTS, Combined Tabber & Stringer）
→ 高温焊接（~250°C，红外/热风）将焊带焊接到电池正面汇流条
→ 焊带背面焊接到下一片电池的背面汇流条（串联）
→ 典型每串 9~13 片电池
→ 焊接质量检验（相机视觉检测对准度/虚焊）
```

### 3.3 新型互联技术

| 技术 | 描述 | 优势 |
|------|------|------|
| **多主栅（MBB, Multi Busbar）** | 汇流条数从 3BB → 5BB → 9BB → 16BB+ | 降低电流传输距离，减少电阻损耗，提升 FF |
| **圆焊带（Round Ribbon）** | 传统扁焊带改圆形，可将反射光聚焦回电池 | 额外光学增益 ~0.1~0.3% |
| **无主栅（MBB + SmartWire 技术）** | 细电线替代焊带，无主栅印刷（Meyer Burger SWCT） | 遮光更少，正面更开放 |
| **导电胶互联** | 低温固化导电胶替代焊接（HJT必须） | 兼容 <200°C 工艺，减少热应力 |

### 3.4 半片（Half-cut）与叠瓦（Shingled）

| 技术 | 描述 | 优势 |
|------|------|------|
| **半片（Half-cut Cell）** | 激光将电池片切成两半，分两路连接 | 电流减半→电阻损耗降低 75%，热斑风险下降 |
| **叠瓦（Shingled Cell）** | 电池片切成条状，相邻条导电胶叠压互联 | 无焊带遮光，封装密度高，组件效率提升 |
| **矩形电池（M10/G12 切半/切三）** | 大尺寸硅片切成多个矩形 | 配合叠瓦或半片，提高组件功率密度 |

## 4. 层压工艺（Lamination）

层压是组件制造的核心工序，决定组件的封装可靠性和寿命。

### 4.1 传统层压工艺

```
叠层组件入炉
    ↓ 抽真空（<1 mbar，~3~5 min）
    ↓ 上加热板加压（~1 bar 气压）
    ↓ 升温至 140~160°C（EVA 熔融，~5~8 min）
    ↓ 固化保温（EVA 交联，~10~15 min，总时间约 20 min）
    ↓ 冷却至 <60°C 出炉
```

**关键指标：交联度（Gel Content）**
- EVA 最低交联度要求：**≥ 65%**（IEC 61215 标准）
- 交联不足 → 分层、黄变、水汽渗透
- 过度交联 → 脆化、应力开裂

### 4.2 双面加热层压（新工艺）

传统单面加热从上方加热，叠层各层温度不均匀。新型双面加热系统：
- 上下同时加热，温度均匀性提升
- 层压时间缩短 **10~30%**（5 分钟单步层压 + 冷却已可实现）
- 适用温度 **>165°C**，配合 PET 基背板

### 4.3 层压参数对比（EVA vs POE）

| 参数 | EVA | POE |
|------|-----|-----|
| 固化温度 | 140~150°C | 150~165°C |
| 固化时间 | 10~15 min | 15~20 min（更长） |
| 最低交联度 | ≥65% | ≥50~65% |
| 水汽阻隔 | 一般 | 优（更低透湿率） |
| PID 抵抗 | 较弱 | 强（无醋酸） |
| 成本 | 低 | 高 15~30% |

## 5. 封装材料详解

### 5.1 封装胶膜（Encapsulant）

| 材料 | 特点 | 主要应用 |
|------|------|---------|
| **EVA（乙烯-醋酸乙烯酯）** | 成本低、工艺成熟、透光率高；弱点：产生醋酸导致PID，易黄变 | 单面/双玻标准组件 |
| **POE（聚烯烃弹性体）** | 低水汽透过率、高PID抗性、无醋酸；成本较高 | 高可靠性/双面组件 |
| **EPE（EVA/POE/EVA 三层）** | 平衡成本与性能，前后分别用不同材料 | 双面bifacial组件 |
| **PVB（聚乙烯醇缩丁醛）** | 早期使用，现特种应用 | BIPV/建材型组件 |

### 5.2 背板（Backsheet）

| 材料 | 典型结构 | 特点 |
|------|---------|------|
| **TPT** | Tedlar/PET/Tedlar | 高防潮、耐候，成本高 |
| **TPE** | Tedlar/PET/EVA | 常用 |
| **KPE/KPK** | PVDF/PET/EVA | 耐候性好，Tedlar 替代 |
| **APE** | PA/PET/EVA | 成本适中 |
| **双玻组件（玻璃背板）** | 3.2 mm 钢化玻璃 | 高可靠性、30年寿命，重量大 |
| 可回收背板 | 新型材料 | 环保趋势，2025年快速增长 |

> **双玻组件趋势**：2024~2025 年双玻（Glass-Glass）组件在地面大型电站中占比持续提升，已超 60%，25 年+ 寿命保证。

### 5.3 前盖玻璃

| 参数 | 要求 |
|------|------|
| 厚度 | 3.2 mm（标准）/2.8 mm（双玻薄型）/2.0 mm（轻量化） |
| 类型 | 超白低铁钢化玻璃 |
| 透过率（AM1.5） | ≥ 91.5% |
| 减反射处理 | 纳米 SiO₂ AR 涂层（增加 2~3% 透过率） |
| 铁含量 | < 0.015%（低铁，减少绿色色调）|

## 6. 接线盒与旁路二极管

**旁路二极管（Bypass Diode）**：防止阴影下被遮挡子串变成功耗负载（热斑）。
- 标准 60/72 片组件：3 个旁路二极管（每 20/24 片一个）
- 半片组件：6 个旁路二极管
- 规格：额定电流 ≥ 15A，反向耐压 ≥ 45V

**接线盒标准**：IP67 或 IP68 防护等级，IEC 62790 认证。

## 7. 组件关键测试项目

| 测试项 | 方法 | 目的 |
|--------|------|------|
| **STC I-V 测试** | 闪光仪（Flash Tester），AM1.5G，1000 W/m²，25°C | 测量组件功率、Voc、Isc、FF |
| **EL（电致发光）成像** | 施加正向电流，NIR 相机成像 | 检测隐裂、暗片、断栅、虚焊 |
| **IR 热成像** | 红外相机在光照下拍摄 | 检测热斑（分流、失效电池） |
| **绝缘耐压（HiPot）** | 组件金属部件与引出线间施加高压 | 验证绝缘安全性 |
| **湿漏电（Wet Leakage）** | 浸水后测量漏电流 | 验证封装完整性 |
| **紫外预处理（UV）** | 15 kWh/m² UV 辐照 | 模拟早期紫外老化 |

## 8. 组件产品认证标准

| 标准 | 内容 |
|------|------|
| **IEC 61215** | 晶硅组件设计鉴定与定型（核心认证，热循环/湿热/冰雹等测试） |
| **IEC 61730** | 组件安全性测试 |
| **IEC 63126** | 高温应用（85°C，湿热 2000h）认证 |
| **IEC 62804** | PID 抗性测试（-1500V，96h） |
| UL 61730 | 北美市场安规 |
| MCS/CEC | 英国/澳大利亚市场 |

## 9. 2025 年组件技术趋势

| 趋势 | 描述 | 驱动因素 |
|------|------|---------|
| **大尺寸（M10/G12）** | 182/210 mm 硅片，600~700 W+ 功率 | 降低系统 BOS 成本 |
| **双面双玻** | 双面发电，30 年质保 | 地面电站 LCOE 优化 |
| **半片/叠瓦** | 降低串联电阻损耗 | 提升组件功率转化效率 |
| **无主栅/圆焊带** | 减少遮光 | 提升短路电流 |
| **POE 胶膜增长** | 取代 EVA，提升可靠性 | PID 风险管控 |
| **智能组件（MLP）** | 集成微逆或优化器 | BIPV/工商业屋顶应用 |

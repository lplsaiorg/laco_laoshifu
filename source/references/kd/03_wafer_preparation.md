# 03 硅片制备

> 来源：[PVEducation - Wafer Slicing](https://www.pveducation.org/pvcdrom/manufacturing-si-cells/wafer-slicing)

## 1. 切片（Wafer Slicing）

### 多线切割（Wire Saw）
现代硅片切割主要使用**多线切割机**（Multi-wire Saw）：

- **砂浆线锯**（Slurry Wire Saw）：钢线 + 碳化硅（SiC）磨料浆料，磨削切割
- **金刚石线锯**（Diamond Wire Saw）：线上固结金刚石颗粒，已成主流（速度更快、损耗更低）

### 切割参数
| 参数 | 典型值 |
|------|------|
| 硅片厚度（光伏） | 150~200 µm |
| 切缝损耗（Kerf Loss） | ~80~100 µm（金刚石线） |
| 线径 | 60~80 µm |
| 切割速度 | 0.5~2 mm/min |

### 切割流程（多晶）
```
多晶大锭 → 带锯切成方砖（Brick）→ 方砖固定在切割板上 → 多线锯切片
```

## 2. 损伤去除（Saw Damage Removal）

线锯切割在硅片表面引入 **5~10 µm** 微裂纹损伤层，需化学腐蚀去除：

- **碱腐蚀**（NaOH 或 KOH，~80°C）：各向异性腐蚀
- **酸腐蚀**（HF + HNO₃混合液）：各向同性腐蚀（常用于多晶）

腐蚀量约 10~20 µm（双面合计），硅片最终厚度约 150~180 µm。

---

## 3. 制绒（Surface Texturing）

目的：在硅片表面形成微结构，**减少反射率**，增加光陷阱效果。

### 单晶硅制绒——碱液各向异性腐蚀

- 腐蚀液：稀 KOH 或 NaOH 溶液（1~3 wt%，~80°C）+ 添加剂（IPA 等）
- 原理：<100> 面腐蚀速率 >> <111> 面，暴露 <111> 面形成**随机金字塔**（Random Pyramids）
- 金字塔尺寸：1~10 µm
- 反射率：从抛光硅的 ~35% 降至 **< 12%**

### 多晶硅制绒——多种方案

| 方案 | 描述 | 效果 |
|------|------|------|
| 酸液各向同性腐蚀（HF+HNO₃） | 随机坑状纹理，不依赖晶向 | 反射率 ~15~20% |
| 机械刻槽 | 激光或切割工具刻出微槽 | 效果有限，成本较高 |
| 等离子刻蚀（RIE） | 反应离子刻蚀形成绒面 | 效果好，设备成本高 |
| 光刻掩模+湿法腐蚀 | 高效但不适合量产 | 实验室用 |

## 4. 清洗（Cleaning）

硅片在各道工序间需严格清洗，去除金属离子、有机物和颗粒污染。

### 标准清洗流程（RCA Clean）

| 步骤 | 溶液 | 目的 |
|------|------|------|
| SC1（标准清洗1） | NH₄OH + H₂O₂ + H₂O（1:1:5） | 去除有机物和颗粒 |
| SC2（标准清洗2） | HCl + H₂O₂ + H₂O（1:1:6） | 去除金属离子 |
| HF 漂洗 | 稀 HF 溶液 | 去除氧化层，获得氢钝化表面 |

清洗后硅片应在洁净环境中尽快进入下道工序。

## 5. 硅片规格演化

| 规格代号 | 尺寸 | 主要时间节点 |
|---------|------|-----------|
| M0 | 156.75 × 156.75 mm | 2015年前主流 |
| M2 | 157.4 × 157.4 mm | ~2018年 |
| M6 | 166 × 166 mm | ~2020年 |
| M10 | 182 × 182 mm | ~2021年起主流 |
| G12 | 210 × 210 mm | ~2021年起量产 |
| 半片（Half-cut） | M10/G12 各半 | 降低电流，减少热损耗 |

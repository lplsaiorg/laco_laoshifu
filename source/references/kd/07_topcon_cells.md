## 2. 工作原理

TOPCon = **Tunnel Oxide Passivated Contact（隧穿氧化钝化接触）**

### 2.1 核心结构

```
【前侧（受光面）】
    正面 Ag 栅线（丝印/LECO优化）
    ─────────────────────────────────
    AlOₓ + SiNₓ:H（正面钝化 + 减反射叠层）
    ─────────────────────────────────
    P+ 硼扩散发射极（B-emitter，轻掺杂）
    ─────────────────────────────────
    N 型 c-Si 衬底（磷掺杂，~180µm）
    ─────────────────────────────────
    超薄 SiOₓ 隧穿氧化层（~1.5 nm）← 核心层①
    ─────────────────────────────────
    磷掺杂多晶硅 poly-Si(n+)（~100~200 nm）← 核心层②
    ─────────────────────────────────
    SiNₓ（背面 poly-Si 保护/减反射）
    ─────────────────────────────────
    背面 Ag 栅线（丝印）
【背侧（可接受散射光）】
```

### 2.2 载流子选择性机制

| 载流子 | 传输路径 | 机制 |
|--------|---------|------|
| **多子（电子）** | c-Si(n) → SiOₓ 隧穿 → poly-Si(n+) → Ag | 量子隧穿效应穿越超薄 SiOₓ（~1.5nm），畅通无阻 |
| **少子（空穴）** | 被 SiOₓ 阻挡，无法到达金属 | SiOₓ 能带结构阻挡空穴迁移，抑制背面复合 |
| **界面复合** | SiOₓ 钝化 c-Si 表面悬挂键，界面态极低 | iVoc 可超过 730 mV |

**高低结增强效果**：poly-Si(n+) 高温晶化后，磷向 c-Si 扩散形成浅 n+/n 高低结，进一步增强载流子分离。

### 2.3 与 PERC 的根本差异

| | PERC 背面 | TOPCon 背面 |
|-|---------|-----------|
| 接触面积 | 局部小开口（激光开口 ~1~5%） | 全面积连续接触 |
| 金属界面 | 铝直接接触 c-Si | 金属接触 poly-Si，不直接触及 c-Si |
| 复合抑制 | 依赖减小接触面积 | 依赖 SiOₓ 隔离金属与 c-Si |
| Voc 潜力 | ~690 mV | ~730 mV+ |

## 3. 完整工艺流程（主流 LPCVD 方案）

```
N 型 CZ 单晶硅片（磷掺杂，~1~3 Ω·cm）
    │
    ├─① 正面制绒 + 背面抛光
    │       正面：KOH/NaOH 各向异性腐蚀 → 随机金字塔（3~6 µm）
    │       背面：HF+HNO₃ 或碱液抛光 → 镜面（减少 poly-Si 寄生吸收）
    │
    ├─② RCA 清洗
    │       SC1（NH₄OH+H₂O₂）→ 去有机物
    │       SC2（HCl+H₂O₂）→ 去金属离子
    │       稀 HF → 去自然氧化层
    │
    ├─③ 背面 SiOₓ 隧穿氧化层生长（~1.5 nm）
    │       方法：湿化学氧化（HNO₃/O₃）/ 热氧化 / UV 氧化（见第4节）
    │
    ├─④ LPCVD 沉积本征 poly-Si（~100~200 nm，背面为主）
    │       温度：580~620°C，SiH₄ 热分解
    │       注意：LPCVD 存在**绕镀**，正面也会沉积薄层（需后续去除）
    │
    ├─⑤ 磷扩散掺杂（POCl₃，850~950°C）
    │       将 poly-Si 掺为 n+ 型
    │       同时高温晶化 poly-Si（非晶 → 多晶硅）
    │
    ├─⑥ 绕镀去除（Wrap-Around Removal）← 关键步骤
    │       湿法 KOH 刻蚀：去除正面及边缘寄生 poly-Si
    │       inline 工艺：~2 分钟 KOH；batch 工艺：~5 分钟
    │       需保留背面 SiOₓ 保护层（在 N₂ 退火阶段自然形成的氧化层）
    │       替代方案：大气干法刻蚀（ADE，分子氟气相刻蚀，速率更高）
    │
    ├─⑦ 正面硼管扩散（P+ 发射极）
    │       气态源：BCl₃（800~1000°C） 或 固态源：PECVD 预沉积 BSG
    │       目标方块电阻：~100~150 Ω/sq（轻掺杂，避免死层）
    │       产生 BSG（硼硅玻璃）需后续 HF 去除
    │
    ├─⑧ BSG 去除（稀 HF 酸洗）
    │
    ├─⑨ PECVD 正面钝化叠层沉积
    │       AlOₓ（~5 nm，ALD 或 PECVD）→ 负固定电荷，钝化正面 P+
    │       SiNₓ:H（~75 nm，PECVD）→ 减反射 + 体钝化氢源
    │
    ├─⑩ PECVD 背面 SiNₓ 沉积（~80~100 nm）
    │       保护 poly-Si(n+)，兼作背面减反射层
    │
    ├─⑪ 丝网印刷金属化
    │       正面：Ag 银浆（细栅线 + 汇流条）
    │       背面：Ag 银浆（细栅线 + 汇流条）
    │       注意：正背面均用 Ag，耗银量约为 PERC 的 1.5~2 倍
    │
    ├─⑫ 共烧结（Co-firing）
    │       峰值温度：750~850°C（低于 PERC 的 ~850°C）
    │       正面 Ag 烧穿 AlOₓ/SiNₓ 与 P+ 形成接触
    │       背面 Ag 与 poly-Si(n+) 形成接触（不穿透 SiOₓ）
    │
    ├─⑬ LECO（激光增强接触优化，可选）
    │       见第 6 节
    │
    └─⑭ I-V 测试分选
```

## 4. SiOₓ 超薄氧化层生长方法

超薄氧化层厚度目标：**~1.5 nm**（精确控制是关键工艺难点）

| 方法 | 工艺条件 | 厚度控制 | 均匀性 | 工业应用 |
|------|---------|---------|--------|--------|
| **湿化学氧化**（HNO₃/O₃水溶液） | 室温~60°C | ~1.5 nm，自限制 | 良好 | 低成本，批量，主流 |
| **热氧化**（干/湿 O₂/H₂O，管式炉） | 800~1000°C | 精确，可控 | 优 | 成熟，能耗较高 |
| **UV 紫外氧化** | 低温 | ~1~2 nm | 良 | 低温在线，部分量产 |
| **等离子氧化**（RF/微波） | 低温 | ~1~2 nm | 良 | 集成于 PECVD 工具 |
| **PEALD**（原子层沉积） | 低温，逐层精确 | 亚纳米精度 | 极优 | 成本高，PECVD辅助方案 |

> **注意**：PECVD 直接沉积的 SiOₓ 均匀性较差，是 PECVD 路线效率离散度高的主要原因之一。PEALD 可解决此问题但增加设备成本。

## 5. poly-Si 沉积技术路线对比

### 5.1 四大路线综合对比

| | LPCVD | PECVD | PEALD+PECVD | PVD（磁控溅射） |
|-|-------|-------|-------------|--------------|
| **成膜速率** | 5~8 nm/min | 10 nm/min | PEALD慢+PECVD快 | 最快 |
| **膜质均匀性** | 优 | 较差（均匀性问题） | 优 | 较差 |
| **绕镀程度** | 严重（完整绕镀） | 轻微（2 mm内） | 轻微 | **无绕镀** |
| **原位掺杂** | 有（慢）/ 配合磷扩 | 原位三合一（SiOₓ+poly+P） | 分步 | 不支持 |
| **量产效率** | 24.9%（GW级） | 验证中 | 验证中 | 24.5% |
| **量产良率** | ~97% | 待验证 | 待验证 | ~95% |
| **设备成本** | 中 | 低于 LPCVD | 高 | 高 |
| **行业占比** | ~67% | ~24% | 小众 | ~9% |
| **代表设备厂** | 拉普拉斯（LAPLACE）、SEMCO | 理想万里晖、捷佳伟创 | — | 江苏杰太 |

### 5.2 各路线特点详述

**LPCVD 路线（行业主流）**
- SiH₄ 在 580~620°C 低压热分解，成膜均匀
- 批次处理（Boat/舟式），单次 4300~8000 片
- 绕镀问题：拉普拉斯水平插片工艺可控制在 **10 mm** 以内
- 石英件消耗成本：石英管寿命 4~12 个月（涂层后），石英舟 ~6 个月，约 200 万元/GW
- GW 级量产效率：**24.9%**，研发效率 25.7%

**PECVD 路线（增长中）**
- 可实现"原位三合一"：SiO₂ 氧化 + poly-Si 沉积 + 原位磷掺杂
- 在线（inline）式生产，设备机台数更少
- 绕镀控制在 **2 mm** 以内（优于 LPCVD）
- 缺陷：SiOₓ 隧穿层均匀性差，效率离散性高；原位掺杂导致陶瓷环导电，缩短石墨舟维护周期；PH₃消耗偏高
- 规模仍在 GW 级验证中

**PVD 路线**
- 磁控溅射靶材方式，氧气电离形成隧穿层，硅靶材轰击形成 poly 层
- **完全无绕镀**是最大优势
- 设备每 30 天需保养 2 天+更换靶材 3 天，停机时间长
- GW 级量产效率 24.5%，良率仅 **95%**（低于 LPCVD 的 97%）
- 设备价格高，现阶段竞争力弱

## 6. 绕镀（Wrap-Around）去除工艺

LPCVD/PECVD 工艺中，poly-Si 会在晶圆正面和边缘形成寄生沉积（绕镀），导致反向击穿漏电（Irev）升高，必须去除。

### 去除方案对比

| 方案 | 工艺条件 | 特点 |
|------|---------|------|
| **湿法 KOH 刻蚀**（inline） | 热 KOH + 添加剂，~2 min | 快速，适合原位掺杂层，主流 |
| **湿法 KOH 刻蚀**（batch） | ~5 min，利用 N₂ 退火氧化层做背面保护 | 适合外扩散掺杂层 |
| **大气干法刻蚀（ADE）** | 分子氟气相刻蚀 | 速率高 10 倍、节水，选择性优，无废液 |

> 去除前需先高效去除表面 SiOₓ 层（影响 KOH 刻蚀速率），并保留背面功能性 poly-Si 层的保护性 SiOₓ。

## 7. 金属化工艺进展

### 7.1 传统丝网印刷 + 共烧结

- 正背面均使用高温 Ag 银浆（~800°C 烧结）
- 正面 Ag 烧穿 AlOₓ/SiNₓ 叠层与 P+ 硼发射极接触
- 背面 Ag 与 poly-Si(n+) 接触，烧结时 Ag 不穿透 SiOₓ 进入 c-Si（验证核心）
- Ag 用量约为 PERC 的 **1.5~2 倍**（正背面均用 Ag，无铝浆替代背面）

### 7.2 LECO（激光增强接触优化）

LECO = **Laser Enhanced Contact Optimization**

**工艺原理**：
- 在常规丝印+烧结完成后，用红外激光（**1064 nm**，功率 18~24 W）施加反向偏压（10~20 V）扫描电池
- 激光局部加热使 Ag-Si 界面形成新相，降低接触电阻率
- 作用：在不穿透 SiOₓ 的前提下，形成低阻、低复合的金属接触

**效果：**

| 参数 | 普通烧结 | LECO 后 |
|------|---------|---------|
| 正面接触电阻率 | 2.9 mΩ·cm² | 1.8 mΩ·cm² |
| 背面接触电阻率 | 14.1 mΩ·cm² | 2.9 mΩ·cm² |
| 效率提升 | 基准 | **+0.6%（绝对值）** |
| 工业电池效率 | ~25.3% | **25.97%** |

LECO 使用不含铝的纯 Ag 银浆效果优于 AgAl 混合浆（VOC 更高），是降低金属化复合的关键。

### 7.3 铜电镀替代银浆（降本核心路线）

银浆成本压力：Ag 约占 TOPCon 非硅成本 **~40%**，且银价波动大（2025 年 Q1 涨 11%）。

**铜电镀方案（Fraunhofer ISE + JXTC 等）**：

| 方案 | 工艺 | 效率 | 银耗降低 |
|------|------|------|--------|
| 激光开槽 + Ni/Cu/Ag 电镀 | 激光刻槽 5 µm，化学镀 Ni + 电镀 Cu + Ag | ~24%（vs 丝印 +0.5%） | >90% |
| Cu 浆（CuBert，Bert Thin Films） | 现有丝印设备，铜浆 + 空气烧结 + LECO | 24%（M10）| 大幅降低 |
| 铜导线直接焊接 | 替代 Ag 主栅，仅细栅用 Ag | — | ~30% |

江苏杰太（JXTC）"水平双面铜金属化"（HD Plate）已建 300 MW 试产线，1 GW 产线在建。

### 7.4 银铜合金电极

晶科、帝科等提出银铜复合电极：
- 在 Ag 浆中掺入 Cu，降低 Ag 用量
- 金属化成本有望下降 **0.01 元/W 以上**
- 兼容现有丝印设备，过渡方案

## 8. 主要工艺挑战与解决路径

| 挑战 | 根本原因 | 当前解决方案 |
|------|---------|------------|
| **烧结峰温 vs 钝化质量** | 750~850°C 烧结 Ag 时，SiOₓ 层可能被金属尖刺破坏 | LECO 后处理（降低烧结峰温要求）+ 增厚 poly-Si 层 |
| **poly-Si 寄生光吸收** | 前侧 poly-Si 绕镀残留吸收短波光 | 严格控制绕镀去除 + 背面 poly-Si 减薄 |
| **银消耗量大** | 正背面均需 Ag，无 Al 浆替代背面 | SMBB 细栅 + 激光转印 + 铜电镀替代 |
| **LPCVD 绕镀** | 管式炉两面沉积 | 水平插片控制在 10 mm + KOH 湿法/ADE 干法去除 |
| **硼扩散均匀性** | 大尺寸硅片（M10/G12）炉管内温度梯度 | 设备炉管均匀性优化 + 气流设计改进 |
| **N型硅片溢价** | N型晶体生长工艺难度高于 P型 | 规模扩大摊薄成本，目前溢价约 6~8%，持续收窄 |

## 9. 效率提升路径与展望

### 近期提升路径（~2025~2026）

```
量产基准（LPCVD + 丝印）：~24.8%
    ↓ + 激光 SE（选择性发射极）        →  +0.2~0.3%  →  ~25.1%
    ↓ + LECO 激光接触优化              →  +0.3~0.6%  →  ~25.5%
    ↓ + 正面 poly-Si 手指（Poly Finger）→  +0.2%      →  ~25.7%
    ↓ + 双面 poly-Si 钝化接触          →  +0.3%      →  ~26.0%
```

### 中长期效率提升方向

| 技术 | 效率提升（预估） |
|------|--------------|
| 背面 poly-Si 减薄（降低寄生吸收） | +0.1% |
| 栅线高宽比优化（降低遮光） | +0.3% |
| 正面金属复合降低（LECO/铜电镀） | +0.2~0.3% |
| 硅片品质提升 | +0.25% |
| 正背面均 poly-Si 钝化（双面 TOPCon） | +0.5~1.0% |
| TOPCon + IBC（背面全钝化接触，无前栅遮光） | 预计 >26.5% |

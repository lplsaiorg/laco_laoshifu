# 05 丝网印刷电池（Al-BSF）

> 来源：[PVEducation - Screen Printed Solar Cells](https://www.pveducation.org/pvcdrom/manufacturing-si-cells/screen-printed-solar-cells)

## 1. 概述

丝网印刷太阳能电池于 **1970年代**首次开发，是目前最成熟的光伏电池制造工艺。Al-BSF（铝背场）丝网印刷电池曾长期主导市场，工艺成熟、成本低廉，是理解光伏制造的基础。

## 2. 完整工艺流程

```
P型CZ/多晶硅片
    ↓ 损伤去除 + 制绒（碱液金字塔/酸液坑状）
    ↓ RCA清洗
    ↓ 磷扩散（POCl₃，~850°C）→ 形成N+发射极
    ↓ 磷玻璃去除（HF酸洗）
    ↓ 边缘隔离（激光刻蚀）
    ↓ PECVD 沉积 SiNₓ:H 减反射层
    ↓ 丝网印刷背面铝浆（全面积）
    ↓ 丝网印刷背面银浆（汇流条）
    ↓ 丝网印刷正面银浆（指栅线 + 汇流条）
    ↓ 烧结（带式炉，峰温 800~850°C）
    ↓ I-V 测试分选
```

## 3. 丝网印刷工艺详解

### 丝网结构
- 金属网格（钢丝网）+ 感光胶掩模
- 未遮盖区域允许金属浆料通过
- 网格目数决定指栅最小宽度（典型指栅宽 **100~200 µm**）

### 印刷过程
1. 硅片置于印刷台
2. 丝网版下压至硅片
3. 橡皮刮刀推动金属浆料通过网孔沉积到硅片表面
4. 进入干燥炉（~150°C）烘干有机溶剂

### 印刷顺序
| 次序 | 材料 | 目的 |
|------|------|------|
| 1st | 背面铝浆（Al Paste） | 覆盖全背面，烧结后形成铝背场（Al-BSF）|
| 2nd | 背面银浆（Ag/Al Paste） | 汇流条，提供可焊接区域 |
| 3rd | 正面银浆（Ag Paste） | 指栅线 + 汇流条，收集光生电流 |

## 4. 铝背场（Aluminum Back Surface Field, Al-BSF）

烧结过程中，铝浆与硅形成铝硅合金：
- Al 大量固溶于 Si 中
- 冷却时 Al 过饱和析出，在界面形成重掺杂 **P+** 层（铝背场）
- Al-BSF 作用：在背面建立内建电场，**推斥少数载流子**（电子），降低背面复合
- 局限性：全面积金属接触导致高界面复合，效率上限 ~20~21%

## 5. 电池结构与关键参数

```
              正面银栅线（Ag Grid）
              |||||||||||||||||||||||||
         ─────────────────────────────  SiNₓ:H 减反射层（~80nm）
    +++  ─────────────────────────────  N+ 磷扩散发射极（~300nm）
         ─────────────────────────────
         ─────────────────────────────  P型硅衬底（~180µm）
         ─────────────────────────────
    ───  ─────────────────────────────  P+ Al-BSF（~5µm Al-Si合金）
              背面铝层（Al Paste）
              背面银汇流条（Ag/Al）
```

| 参数 | 典型值 |
|------|------|
| 正面指栅宽度 | 100~150 µm |
| 指栅间距 | 2~3 mm |
| 遮光损耗 | 5~10% |
| 电池效率（单晶） | 19~20.5% |
| 电池效率（多晶） | 17~18.5% |

## 6. 制绒对比（单晶 vs 多晶）

### 单晶制绒（适合 CZ 硅片）
- 碱液（KOH/NaOH）各向异性腐蚀
- 暴露 <111> 面，形成均匀随机金字塔
- 反射率从 ~35% 降至 **10~12%**

### 多晶制绒方案
由于多晶晶粒方向随机，单一碱液腐蚀效果不均匀，多种方案可选：
1. **酸液各向同性腐蚀**（HF+HNO₃）：形成坑状结构，反射率 ~15~20%
2. **机械纹理化**：激光或切削工具
3. **各向同性化学腐蚀**（基于缺陷）
4. **等离子刻蚀（RIE）**：效果最佳，设备成本高

## 7. 工艺优化方向

| 优化点 | 技术手段 | 效果 |
|--------|---------|------|
| 减小指栅宽度 | 改善印刷浆料流变性、高目数丝网 | 降低遮光 |
| 选择性发射极（SE） | 激光掺杂/双次印刷 | 提高 Voc、Jsc |
| 减小接触复合 | 减小金属覆盖面积 | 提高 Voc |
| 增大基板尺寸 | M10/G12 大尺寸硅片 | 提升组件功率 |

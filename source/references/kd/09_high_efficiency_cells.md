# 09 高效电池结构

> 来源：[PVEducation - High Efficiency Solar Cells](https://www.pveducation.org/pvcdrom/manufacturing-si-cells/high-efficiency-solar-cells) | [Buried Contact Solar Cells](https://www.pveducation.org/pvcdrom/manufacturing-si-cells/buried-contact-solar-cells)

## 1. PERL 电池（Passivated Emitter with Rear Locally Diffused）

### 背景
PERL 电池是 UNSW（澳大利亚新南威尔士大学）Michael Green 课题组开发的实验室高效电池，代表了硅电池工艺的最高水平之一。

### 结构特点
```
              细金属栅线（< 20 µm 宽，Ti/Pd/Ag 多层）
              |||||||||||||||||||||||
  热氧化钝化  ─────────────────────────────  倒金字塔纹理（减反射）
  （SiO₂）   ─────────────────────────────  轻掺杂 N+ 发射极
             ─────────────────────────────
             ─────────────────────────────  P 型 FZ 硅衬底
             ─────────────────────────────
  热氧化钝化  ─────────────────────────────  高质量背面 SiO₂ 钝化
  （SiO₂）   
        ↕ 局部 P++ 重扩散 + 金属接触（仅在接触点）
```

### 关键技术特征

| 特征 | 描述 | 效益 |
|------|------|------|
| 轻磷扩散发射极 | 方块电阻 100~200 Ω/sq（避免"死层"） | 提高蓝光响应 |
| 细金属线（< 20 µm） | 光刻工艺定义 | 遮光损耗 < 3% |
| 细间距指栅 | 低横向电阻 | 降低发射极横向电阻 |
| Ti/Pd/Ag 多层金属化 | Ni silicide 极低接触电阻 | 降低接触复合 |
| 背面热 SiO₂ 全面积钝化 | 极低表面复合速率（< 10 cm/s） | 提高 Voc |
| 局部背面重扩散 P++ | 仅在接触点重掺杂，降低背面接触复合 | 兼顾低接触电阻和低复合 |
| 倒金字塔（Inverted Pyramid）纹理 | 光刻 + 各向异性腐蚀 | 优化光陷阱 |

### 历史效率记录
- 1989 年：22.8%（PERC 原型）
- 1999 年：**24.7%**（FZ 硅，PERL 结构，AM1.5G）
- 2025 年：~26.8%（最新纪录，采用更先进工艺）

### 实际应用参数（1990 年代太阳能赛车用）
| 参数 | 数值 |
|------|------|
| 面积 | 22 cm² |
| 效率 | 23.5% |
| Voc | 703 mV |
| Isc | 914 mA（Jsc = 41.3 mA/cm²） |
| FF | 0.81 |
| Vmp | 600 mV |

## 2. 埋栅接触电池（Laser Grooved Buried Contact, LGBC）

### 概述
埋栅接触电池是 UNSW 开发的**商业高效技术**，基于激光刻槽 + 化学电镀金属，比标准丝网印刷电池效率高 **~25%**（相对值）。

### 核心创新：激光刻槽埋栅

```
截面示意：
         细线金属（Cu，大体积，埋入槽中）
              |||||||
    ─────────────────────────────  SiNₓ:H 减反射层
    ─────────────────────────────  N+ 选择性发射极
    ─────────────────────────────
    ─────────────────────────────  P 型硅衬底
    ─────────────────────────────
    ─────────────────────────────  背面 N+ 重扩散
         背面金属（Ni/Cu/Ag）
```

### 关键优势分析

| 优势 | 原理 |
|------|------|
| 低遮光损耗（2~3%） | 槽内金属宽度极小（~20 µm），高深宽比金属体积大 |
| 低发射极横向电阻 | 指栅间距更小（因遮光面积小），横向传输距离短 |
| 低接触电阻 | Ni 硅化物界面 + 大接触面积（槽侧壁） |
| 低发射极复合 | 轻掺杂发射极（非屏印重掺杂死层），可自对准选择性发射极 |
| 低金属栅线电阻 | 槽内铜（Cu）电阻率低 + 大截面积 |

对比丝网印刷：
| | 丝网印刷 | 埋栅接触 |
|-|---------|--------|
| 遮光损耗 | 10~15% | 2~3% |
| 指栅宽度 | 100~200 µm | ~20 µm |
| 金属 | Ag 浆 | Ni/Cu/Ag 电镀 |
| 接触电阻 | 较高 | 低（Ni 硅化物） |
| 成本（$/W） | 相近（效率补偿） | 相近 |

### LGBC 工艺流程

```
硅片
    ↓ 重磷扩散（整体N+）
    ↓ SiNₓ 减反射层沉积（PECVD）
    ↓ 激光刻槽（Laser Grooving）切割出细槽（~30 µm 宽，~40 µm 深）
    ↓ 碱液清洗（去除激光损伤层）
    ↓ 轻磷扩散（在槽内形成选择性重掺杂发射极，槽间区保持轻掺杂）
    ↓ 化学镀镍（Electroless Ni Plating，形成 Ni 硅化物）
    ↓ 电镀铜（Cu，填充槽体）
    ↓ 电镀银（Ag，可焊接保护层）
    ↓ 背面金属化
    ↓ 烧结测试
```

## 3. 高效电池设计原则总结

来自 UNSW 早期研究整理：

| 原则 | 技术手段 |
|------|---------|
| 最小化发射极复合 | 轻掺杂发射极（避免死层），避免重金属扩散 |
| 最小化横向电阻损耗 | 细间距指栅，细指栅线 |
| 最小化遮光损耗 | 细指栅线（< 20 µm），光刻或激光定义 |
| 最小化接触复合 | 局部小面积金属接触 + 接触处重掺杂（自对准） |
| 最小化金属栅线电阻 | 高深宽比金属体积，低电阻率金属（Cu） |
| 最优背面钝化 | 高质量热氧化 SiO₂ + 局部背面扩散 |
| 低接触电阻 | 金属硅化物（Ti/Ni silicide）界面处理 |
| 优化减反射 | 精确厚度 SiNₓ/MgF₂ 等 ARC，双层 DARC |

## 4. IBC 电池（Interdigitated Back Contact）

（SunPower / 现 Maxeon Technologies 开发）

- 正面无金属栅线，**零遮光损耗**
- P+、N+ 发射极和基极交叉指状排布于背面
- 背面全面积金属化
- 效率：SunPower 量产 **>25%**，与 HJT 结合（IBC-HJT）可达 **26.7%**
- 工艺复杂，成本高，主要用于高端应用

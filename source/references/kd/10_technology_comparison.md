## 3. 工艺流程步骤对比

### Al-BSF（传统，~10步）
```
制绒 → 磷扩散 → 去磷玻璃 → 边缘隔离 → PECVD SiNₓ
→ 印背面Al → 印背面Ag → 印正面Ag → 烧结 → 测试
```

### PERC（~12步）
```
制绒 → 磷扩散 → 去磷玻璃 → 边缘隔离 → ALD/PECVD AlOₓ
→ PECVD SiNₓ（背/前）→ 激光开口(LCO) → 印背面Al → 印背面Ag
→ 印正面Ag → 烧结 → LID处理(可选) → 测试
```

### TOPCon（~15~18步）
```
制绒(正面)+抛光(背面) → 背面SiOₓ → LPCVD poly-Si(n)
→ 高温退火晶化 → 背面磷扩散去除(湿法) → 正面硼扩散
→ BSG去除 → 前AlOₓ+SiNₓ → 背SiNₓ → 印正面Ag
→ 印背面Ag → 烧结 → 测试
```

### HJT（~4~6步）
```
制绒+清洗 → PECVD a-Si:H双面（i/p前 + i/n背）
→ PVD ITO双面 → 印低温银浆（前+背）→ 低温退火 → 测试
```

## 5. 市场份额演变

```
年份    Al-BSF    多晶    PERC    TOPCon    HJT
2018    ~40%     ~40%    ~20%    <1%      <1%
2020    ~15%     ~20%    ~60%    ~5%      ~1%
2022    ~5%      ~10%    ~70%    ~15%     ~3%
2024    ~1%      ~3%     ~40%    ~52%     ~7%
2025E   <1%      <1%     ~20%    ~70%     ~10%
```

**2025 年趋势：**
- TOPCon 成为绝对主流，新产线几乎全部为 TOPCon
- HJT 在高端市场快速增长，降本路线清晰
- PERC 产能存量消化中，新增几乎停止
- Al-BSF 退出历史舞台

## 6. 技术路线选择矩阵

| 场景 | 推荐技术 | 原因 |
|------|---------|------|
| 地面大型电站（追求 $/W） | TOPCon | 效率与成本平衡最优 |
| 高温高辐射地区（沙漠/东南亚） | HJT | 温度系数最优，年发电量最高 |
| 屋顶/BIPV（面积受限） | TOPCon / HJT | 高效率组件 |
| 太阳能赛车/空间 | PERL / IBC-HJT | 最高效率 |
| 存量 PERC 产线改造 | TOPCon（兼容部分设备） | 设备复用度高 |
| 下一代叠层研发 | HJT（作底电池） | 低温兼容钙钛矿 |

## 7. 未来技术路线图

```
2025          2027          2030          2035+
TOPCon主流  → TOPCon/HJT并行 → HJT扩大 → 叠层电池商业化
                              钙钛矿单结  钙钛矿/Si Tandem
                                          效率目标 >30%
```

**关键突破方向：**
- **TOPCon**：减少 Ag 用量（铜电镀），多晶硅层减薄降低寄生吸收
- **HJT**：铜电镀替代低温 Ag 浆，ITO 替代（AZO/ICO），薄片工艺
- **钙钛矿叠层**：稳定性 > 25 年，铅替代，大面积均匀性
- **IBC 结合**：TOPCon-IBC 或 HJT-IBC（26~28% 效率）

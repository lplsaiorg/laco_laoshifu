# 01 硅原料提纯

> 来源：[PVEducation - Refining Silicon](https://www.pveducation.org/pvcdrom/manufacturing-si-cells/refining-silicon)

## 1. 原料概述

二氧化硅（SiO₂）是地壳中含量最丰富的矿物。光伏级高纯硅的制造分为两个阶段：
1. 去除氧元素 → 冶金级硅（MG-Si）
2. 进一步提纯 → 电子/太阳能级硅

## 2. 冶金级硅（Metallurgical Grade Silicon, MG-Si）

### 原料
- 高纯石英岩（SiO₂），低铁、铝等金属杂质含量

### 工艺
在电弧炉中与碳（煤、木炭）在 **1500~2000°C** 下发生还原反应：

```
SiO₂ + C → Si + CO₂
```

### 特性
| 参数 | 数值 |
|------|------|
| 纯度 | ~98% |
| 主要杂质 | C、碱土金属、过渡金属、B（>50 ppmw）、P（>100 ppmw） |
| 生产成本 | 数美元/kg |
| 能耗 | 14~16 kWh/kg |
| 全球产量（2010年） | ~180万吨/年（其中12%用于光伏） |

> 过渡金属在硅带隙中形成深能级，导致高复合活性；B、P掺杂浓度过高，无法直接用于电子器件。

## 3. 电子级硅（Electronic Grade Silicon）

### 西门子法（Siemens Process）

**步骤一：氯化反应**

粉末 MG-Si 在 **300°C** 流化床中与无水盐酸（HCl）反应：

```
Si + 3HCl → SiHCl₃ + H₂
```

同时，Fe、Al、B 等杂质转化为各自的卤化物（FeCl₃、AlCl₃、BCl₃）。

**步骤二：精馏提纯**

SiHCl₃（沸点 31.8°C）低沸点特性，通过精馏与杂质卤化物分离。
→ 提纯后电活性杂质（Al、P、B、Fe、Cu、Au）< **1 ppba**

**步骤三：氢还原沉积**

在 **1100°C**、200~300 小时条件下：

```
SiHCl₃ + H₂ → Si + 3HCl
```

硅沉积在真空腔内的多晶硅细棒上，形成直径 **150~200 mm** 的高纯多晶硅棒（Polysilicon Rod）。

## 4. 太阳能级硅（Solar Grade Silicon）

- 纯度介于冶金级与电子级之间
- 光伏对杂质容忍度高于集成电路，探索替代低成本制备路线
- 主要方向：流化床反应器法（FBR，使用 SiH₄ 硅烷气体），成本更低、能耗更小

## 5. 三类硅纯度对比

| 等级 | 纯度 | 主要用途 | 成本 |
|------|------|--------|------|
| 冶金级（MG-Si） | ~98% | 冶金/化工 | 低 |
| 太阳能级（SoG-Si） | 99.9999%（6N） | 光伏电池 | 中 |
| 电子级（EG-Si） | 99.9999999%（9N+） | 半导体芯片 | 高 |

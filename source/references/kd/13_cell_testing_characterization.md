## 1. 标准测试条件（STC）

所有光伏器件性能对比须在 **标准测试条件（Standard Test Conditions, STC）** 下进行：

| 参数 | 标准值 |
|------|------|
| 辐照度（Irradiance） | **1000 W/m²** |
| 光谱（Spectrum） | **AM1.5G**（IEC 60904-3） |
| 电池温度（Cell Temperature） | **25°C** |

> **AM1.5G**：太阳光穿过 1.5 倍大气厚度（高度角 ~41.8°）后到达地面，是中纬度地区典型日照条件的全球（Global）辐照标准谱。

## 2. I-V 曲线测量（核心表征）

### 2.1 I-V 曲线及关键参数

```
          Isc
           │╲
           │  ╲
电         │    ╲
流         │      ╲ MPP（最大功率点）
I(A)       │        ╲
           │          ╲
           │            ╲───────
           0────────────────────── 电压 V(V)
                               Voc
```

| 参数 | 符号 | 定义 |
|------|------|------|
| 短路电流 | **Isc** | V=0 时的电流，正比于光吸收量 |
| 开路电压 | **Voc** | I=0 时的电压，反映少子复合水平 |
| 最大功率点电流 | Imp | I-V 曲线功率最大处的电流 |
| 最大功率点电压 | Vmp | I-V 曲线功率最大处的电压 |
| 最大功率 | **Pmax** | Imp × Vmp（W） |
| 填充因子 | **FF** | Pmax / (Voc × Isc)，理想方形度，80~85% |
| 转换效率 | **η** | Pmax / (Pin × A)，Pin=1000 W/m² |

**等效电路（双二极管模型）：**

```
                Rs（串联电阻）
光生电流 Iph ── 二极管1（理想度n1）── 二极管2（n2）── 并联电阻 Rsh ── 负载
```
- **Rs 大** → FF 下降（电流被消耗）
- **Rsh 小** → Voc 和 FF 下降（漏电）

### 2.2 测量设备——闪光仪（Flash Tester / Solar Simulator）

工业生产线上每片电池 / 每块组件必须经过闪光仪测试：

| 参数 | 工业标准 |
|------|---------|
| 光源 | 脉冲氙灯（~10 ms 脉冲） |
| 光谱等级 | Class A（AM1.5G 各波段偏差 < 25%） |
| 均匀度 | Class A（± 2% 以内） |
| 温度控制 | 25°C ± 1°C（水冷/气冷台） |
| 测量速度 | ~0.5~2 s/片（工业产线） |
| 精度 | Pmax 误差 < ±2% |

## 3. 外量子效率（EQE）与光谱响应（SR）

### 3.1 外量子效率（External Quantum Efficiency, EQE）

```
EQE(λ) = 每个入射光子对应的输出电子数

EQE(λ) = Jsc(λ) / [e × Φ(λ)]
```

- **EQE(λ)** 反映不同波长光的收集效率
- 单晶硅 EQE 峰值在 ~900~1000 nm，紫外端因表面复合而下降
- 叠层电池须对每个子电池分别测量（用滤光片分离）

### 3.2 内量子效率（IQE）

```
IQE(λ) = EQE(λ) / [1 - R(λ)]
```
去除反射损失后的"真实"内部收集效率。IQE 下降反映体内复合或收集效率问题。

### 3.3 光谱响应（Spectral Response, SR）

```
SR(λ) [A/W] = EQE(λ) × e × λ / (h × c)
```

积分可得电池理论 Jsc：

```
Jsc = ∫ SR(λ) × Φ_AM1.5(λ) dλ
```

### 3.4 测量设备

- **单色仪系统**（Grating-based）：连续可调波长（300~1800 nm），精度高
- **滤光片系统**（Filter-based）：离散波长，速度更快，生产检测用
- 白光偏置（White-light Bias）：确保高光强下测量结果准确

## 4. 电致发光成像（EL, Electroluminescence Imaging）

### 4.1 原理

对电池/组件施加**正向偏置电流**，P-N 结辐射复合发出近红外光（~1100 nm），用**近红外相机（NIR CCD/InGaAs）**成像：

```
施加正向电流 → 少子注入 → 辐射复合 → NIR 光发射
高质量区域：亮区
缺陷/高复合区：暗区
```

### 4.2 可检测缺陷

| 缺陷类型 | EL 图像特征 |
|---------|-----------|
| 裂片/隐裂（Micro-crack） | 暗纹/暗区，垂直或斜向 |
| 断栅线（Broken Fingers） | 条状暗纹 |
| 虚焊（Poor Solder Joint） | 汇流条区暗点/暗区 |
| 局部高串联电阻 | 均匀变暗区域 |
| 旁路二极管短路 | 整串暗条 |
| 电位诱发衰减（PID） | 均匀亮度下降 |
| 分流（Shunting） | 孤立亮点（电流集中处） |

### 4.3 测试时机（生产线）

```
串焊后 → EL（检测焊接质量）
层压后 → EL（检测层压引入隐裂）
装框后 → EL（最终确认）
现场运维 → EL（室外/室内 dEL）
```

### 4.4 现场检测进展（2025年）

- **日间 EL（dEL）**：可在光照下（特殊相机+锁相放大/调制电流技术）拍摄 EL，适合现场大规模巡检
- **无人机 EL（Drone EL）**：搭载 NIR 相机的无人机，对地面电站快速扫描
- **AI 识别**：ResNet152 等深度学习模型自动分类 EL 缺陷，分类准确率 **>90%**

## 5. 光致发光成像（PL, Photoluminescence Imaging）

### 5.1 原理

用**激光**（通常 810 nm 或 980 nm）激发硅片/电池，检测硅辐射复合发出的光（~1150 nm），成像反映少子寿命分布：

```
激光照射 → 产生电子-空穴对 → 辐射复合 → PL 信号
高寿命区域：亮
高复合（缺陷）区域：暗
```

### 5.2 PL vs EL

| | PL | EL |
|-|-----|-----|
| 激励方式 | 激光光照 | 外加正向电流 |
| 适用阶段 | **硅片 / 扩散后 / 任意中间工序** | 完成金属化后的电池/组件 |
| 主要信息 | 少子寿命分布、体缺陷 | 电池/组件电气性能 |
| 设备成本 | 中 | 中 |
| 现场应用 | 室内为主 | 室内+室外均可（dEL） |

### 5.3 PL 在硅片/电池制造中的应用

| 阶段 | 信息 |
|------|------|
| 硅片 | 少子寿命分布，识别低寿命区域 |
| 制绒后 | 表面钝化质量 |
| 扩散后 | 发射极均匀性 |
| ARC 后 | SiNₓ 体钝化效果（氢化程度） |
| 电池完成后 | 综合效果，可推算 Voc |

## 6. 暗 I-V 测量（Dark IV）

不照光情况下正向偏置，测量二极管特性：

```
I = I₀ × [exp(qV/nkT) - 1] - Iph

暗态（Iph=0）：I = I₀ × [exp(qV/nkT) - 1]
```

**暗 IV 可提取参数：**
- **理想因子 n（Ideality Factor）**：n=1 理想，n=2 复合主导（表面/体）
- **反向饱和电流 I₀**：越小 → Voc 越高
- **串联电阻 Rs**（高压段斜率）
- **并联电阻 Rsh**（低压段斜率）

---

## 7. Suns-Voc 测量

在**无金属化/开路条件**下测量 Voc 与光强关系，排除 Rs 影响，提取"伪效率"（Pseudo-efficiency）和"伪填充因子"（Pseudo-FF, pFF）：

```
FF_loss = pFF - FF  → 量化串联电阻对 FF 的损耗
```

## 8. 少子寿命测量（Minority Carrier Lifetime）

| 方法 | 原理 | 适用对象 |
|------|------|---------|
| **微波光电导衰减（µW-PCD）** | 激光脉冲注入后微波反射衰减 | 硅片（体寿命） |
| **准稳态光电导（QSSPC）** | 不同光强下稳态光电导 | 硅片/电池（Sinton法）|
| **RF 光电导** | 射频传感检测光电导 | NIST 标准测量 |

**高效电池对少子寿命要求：**

| 电池类型 | 硅片有效寿命要求 |
|---------|--------------|
| Al-BSF（~20%） | > 50 µs |
| PERC（~22%） | > 200 µs |
| TOPCon（~25%） | > 500 µs |
| HJT（~25%+） | > 1000 µs |

## 9. 红外热成像（IR Thermography）

对组件施加正向电流或在光照下，红外热像仪拍摄温度分布：

| 缺陷 | 热像特征 |
|------|---------|
| 热斑（Hot Spot） | 被遮挡电池温度异常升高（可达 100°C+） |
| 旁路二极管失效 | 接线盒过热 |
| 分流/短路 | 局部过热点 |
| 高串联电阻 | 焊带/汇流条发热 |

## 10. 大规模产线在线检测（AOI）

| 检测项 | 方法 | 检测速度 |
|--------|------|---------|
| 外观缺陷（崩边/脏污） | CCD 相机视觉检测 | ~3000 片/h |
| 制绒均匀性 | 反射率仪/颜色相机 | 在线实时 |
| 扩散方块电阻 | 四探针/涡流法 | 在线或抽检 |
| 少子寿命（扩散后） | PL 成像 | ~1 片/2 s |
| 印刷对准/断线 | CCD 视觉 | 每片 |
| 最终 IV（闪光仪） | STC 测量 | ~0.5 s/片 |
| 分选（Sorting） | 按 Pmax / Isc 分档 | 同上 |

## 11. 关键表征指标速查

| 指标 | 典型范围（量产） | 优劣判断 |
|------|--------------|---------|
| Voc（TOPCon） | 700~730 mV | 越高越好，反映复合抑制 |
| Jsc（TOPCon） | 41~42 mA/cm² | 越高越好，反映光吸收+收集 |
| FF（TOPCon） | 82~84% | 越高越好，反映串/并联电阻 |
| 少子寿命（N型硅片） | >1 ms | 越高越好 |
| EQE@400nm | >90% | 越高越好（正面钝化质量） |
| EQE@1000nm | >80% | 越高越好（背面钝化/光陷阱）|
| 串联电阻 Rs | <0.5 Ω·cm² | 越低越好 |
| 并联电阻 Rsh | >1000 Ω·cm² | 越高越好 |

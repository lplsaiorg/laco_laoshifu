# 06 PERC 钝化发射极背面电池

> 来源：[PV-Manufacturing.org - PERC Solar Cells](https://pv-manufacturing.org/perc-solar-cells/)

## 1. 概述

**PERC（Passivated Emitter and Rear Cell）** 钝化发射极背面电池：

- 首次提出：1983 年，澳大利亚新南威尔士大学（UNSW）
- 1989 年创效率纪录：22.8%（UNSW，A.W. Blakers 等）
- 商业化量产：~2013 年起规模化，成为十年间主流技术
- 2025 年：逐步被 TOPCon 取代，新增产能占比下降

## 2. 与 Al-BSF 的核心区别

```
Al-BSF（传统）：
    正面 → 硅衬底 → 全面积铝背场 → 铝/银背面电极
    
PERC（改进）：
    正面 → 硅衬底 → 介质钝化层（AlOₓ/SiNₓ）→ 激光局部开口 → 局部铝接触
```

**改进效果：**
| 改进点 | 机制 | 效益 |
|--------|------|------|
| 背面介质钝化 | AlOₓ 负固定电荷密度，降低背面复合 | Voc 提升 10~20 mV |
| 介质反射镜 | 近带隙光子被高反射介质膜反射，二次穿越硅片 | Jsc 提升 ~1 mA/cm² |
| 局部铝接触 | 减小金属-硅接触面积，降低接触复合 | Voc 进一步提升 |

## 3. 完整工艺流程

```
P型CZ单晶硅片（主流）
    ↓ 制绒（碱液金字塔）+ 清洗
    ↓ 磷扩散（POCl₃）→ N+ 前侧发射极
    ↓ 磷玻璃去除 + 边缘隔离
    ↓ PECVD 沉积 AlOₓ/SiNₓ 背面钝化叠层  ← PERC 新增步骤①
    ↓ PECVD 沉积 SiNₓ:H 正面减反射层
    ↓ 激光局部开口（Laser Contact Opening, LCO）← PERC 新增步骤②
    ↓ 丝网印刷背面铝浆（局部接触）
    ↓ 丝网印刷背面银浆汇流条
    ↓ 丝网印刷正面银浆
    ↓ 共烧结（~800°C）
    ↓ LID 消除处理（镓掺杂则跳过）← PERC 新增步骤③（可选）
    ↓ 测试分选
```

## 4. 背面钝化叠层（AlOₓ/SiNₓ）

### 氧化铝（Al₂O₃ / AlOₓ）

| 特性 | 说明 |
|------|------|
| 沉积方法 | ALD（原子层沉积）或 PECVD |
| 厚度 | ~5~15 nm |
| 核心机制 | 内在**负固定电荷**（~10¹² cm⁻²），对 P 型硅形成场效应钝化 |
| 化学钝化 | Si-O 键饱和悬挂键，降低界面态密度 |
| 发明 | 埃因霍温理工大学 + IMEC（~2006年） |

### 覆盖 SiNₓ 层
- 厚度：~80~100 nm
- 作用：保护 AlOₓ 层（AlOₓ 单独暴露在正电荷 SiNₓ 下会失效）、增强背面反射、提供机械保护
- 与 AlOₓ 叠层合用时效果显著优于单层

## 5. 激光局部开口（Laser Contact Opening, LCO）

- 激光（通常 532 nm 绿激光 或 355 nm UV 激光）
- 烧蚀背面 AlOₓ/SiNₓ 钝化层，暴露局部硅面
- 点状或线状开口图案
- 开口率：~1~5%（面积比）
- 铝浆只在开口处与硅合金化，形成局部 Al-BSF 接触

## 6. 光致衰减（LID）问题与解决

P 型 CZ 硅 PERC 电池存在**硼氧复合物（B-O）**导致的光致衰减：
- 首年功率衰减 ~2%（远高于 TOPCon/HJT 的 ~1%）

**解决方案：**
| 方案 | 原理 |
|------|------|
| LID 消除退火（LID Elimination） | 高温短时退火打破 B-O 复合物 |
| **镓（Ga）掺杂**（现主流） | Ga 取代 B 作为掺杂剂，无 B-O 复合，从源头消除 LID |

## 8. PERC 到 PERC+ / Bifacial PERC

- **双面 PERC（Bifacial PERC）**：背面电极改为细栅线（而非全面积铝），允许背面受光，双面发电
- 双面率（Bifaciality）：~70~80%
- 现商业 PERC 产品几乎全部为双面版本

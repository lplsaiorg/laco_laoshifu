# 08 HJT 硅异质结电池

> 来源：[PV-Manufacturing.org - Silicon Heterojunction Solar Cells](https://pv-manufacturing.org/silicon-heterojunction-solar-cells/)

## 1. 概述

**HJT（Heterojunction with Intrinsic Thin-Layer）** 硅异质结电池：

- 1992 年 Sanyo（现 Panasonic）开发 HIT® 电池（Heterojunction with Intrinsic Thin-layer）
- 核心创新：在 c-Si 与掺杂 a-Si:H 之间引入本征 a-Si:H 缓冲层，大幅降低界面复合
- 效率记录：Kaneka 公司 **26.7%**（79 cm² 小面积，IBC-HJT）
- 2025 年量产 HJT 双面微晶电池平均效率可达 **26.15%**（Huasun）

## 2. 电池结构

```
前面（受光面）
─────────────────────────────────────────────
    正面银栅线（Ag Grid，低温导电银浆）
─────────────────────────────────────────────
    ITO（氧化铟锡，透明导电层，~70 nm）
─────────────────────────────────────────────
    p-type a-Si:H（掺硼非晶硅，~5 nm）← P-N 结
─────────────────────────────────────────────
    i-type a-Si:H（本征非晶硅，~5 nm）← 钝化缓冲层
─────────────────────────────────────────────
         N 型 c-Si 衬底（吸收层，~150 µm）
─────────────────────────────────────────────
    i-type a-Si:H（本征非晶硅，~5 nm）← 背面钝化
─────────────────────────────────────────────
    n-type a-Si:H（掺磷非晶硅，~5 nm）← 背表面场
─────────────────────────────────────────────
    ITO（背面透明导电层，~100 nm）
─────────────────────────────────────────────
    背面银栅线（Ag Grid）
背面（可受散射光）
```

**整体叠层：p-a-Si:H / i-a-Si:H / n-c-Si / i-a-Si:H / n-a-Si:H（p/i/n/i/n 结构）**

## 3. 关键材料

### 氢化非晶硅（a-Si:H）
- 裸非晶硅缺陷密度极高，氢化后缺陷密度大幅下降
- 带隙（~1.7 eV）略宽于 c-Si（1.12 eV），形成异质结
- 沉积方法：**PECVD**（等离子增强化学气相沉积）
- 本征层（i 层）厚度 ~5~10 nm，掺杂层 ~5~15 nm

### 透明导电氧化物（TCO）
- 最常用：**ITO（氧化铟锡, In₂O₃:Sn）**
- 沉积方法：磁控溅射（PVD Sputtering）
- 功能：
  - 横向导电（载流子侧向传输至金属栅线）
  - 与金属形成良好欧姆接触
  - 兼作减反射层（前侧 ITO 厚度优化减反射）
- 前侧 ITO：优化透光率和电导率（~70~80 nm）
- 背侧 ITO：优化红外低吸收（~100~120 nm）

### 低温银导电浆料
- 烧结温度 **< 200°C**（普通高温银浆在 > 300°C 会破坏 a-Si:H）
- 成本高于高温浆料，是 HJT 降本的重要方向
- 替代方向：铜电镀（Cu Plating）

## 4. 完整工艺流程（仅 4~6 步）

```
N 型 CZ 单晶硅片
    ↓ 湿化学制绒（碱液 KOH/NaOH）+ RCA 清洗
    ↓ PECVD 双面沉积 i/p a-Si:H（正面）+ i/n a-Si:H（背面）
    ↓ PVD 磁控溅射 ITO（双面）
    ↓ 丝网印刷（或电镀）低温银浆栅线
    ↓ 低温退火（200~250°C，30~60 min）固化银浆
    ↓ 测试分选
```

**工序数量对比（简化）：**
| 技术 | 主要工序数 |
|------|---------|
| Al-BSF | ~10 |
| PERC | ~12 |
| TOPCon | ~15~18 |
| **HJT** | **~4~6** |

## 5. HJT 核心优势

### 极低温度系数
| 技术 | 温度系数 |
|------|---------|
| 标准同质结 | -0.45%/°C |
| PERC | -0.35%/°C |
| TOPCon | -0.30%/°C |
| **HJT** | **-0.24~-0.27%/°C** |

→ 在实际高温工作环境（60~80°C）下，HJT 输出功率优势更明显，LCOE 更低。

### 极高开路电压
- SHJ 的完美界面钝化使 Voc 可超过 **750 mV**
- 内在硅太阳能电池效率极限 ~29%，HJT 是最接近极限的路线之一

### 低衰减
- 无 LID 问题（N 型衬底 + 无 B-O 复合）
- 首年衰减 ≤ 1%，年均 0.25~0.35%（优于 PERC/TOPCon）

### 对称结构，天然双面
- p/i/n/i/n 结构近似对称，正背面均可受光
- 双面率（Bifaciality）：~90~95%（优于 PERC ~70%、TOPCon ~75%）

### 低温工艺，兼容柔性衬底
- 全程 **< 200°C**，适合薄片（< 100 µm）和柔性应用
- 天然适合与钙钛矿（Perovskite）叠层串联（Tandem）

## 6. HJT 挑战与成本

| 挑战 | 描述 |
|------|------|
| ITO 成本（In 资源） | 铟（In）是稀有金属，长期供应风险 |
| 低温银浆成本高 | 低温导电浆料比高温浆料贵 2~3 倍 |
| PECVD/PVD 设备成本 | 设备投资高，产能扩张资金需求大 |
| 铜电镀替代（Cu Plating） | 降本关键路线，仍在开发中 |

## 8. 下一代：钙钛矿/HJT 叠层（Perovskite/SHJ Tandem）

- HJT 作为底电池（硅，~1.12 eV 带隙）
- 钙钛矿作为顶电池（可调带隙 1.6~1.8 eV）
- 理论效率 > 35%，实验室已突破 33%（2024年）
- HJT 低温工艺与钙钛矿制备温度兼容，天然优势

# 04 电池基础工艺

> 来源：[PVEducation - Emitter Diffusion](https://www.pveducation.org/pvcdrom/manufacturing-si-cells/emitter-diffusion) | [Anti Reflection Coatings](https://www.pveducation.org/pvcdrom/manufacturing-si-cells/anti-reflection-coatings)

## 1. 扩散掺杂（Emitter Diffusion）

目的：在硅片表面形成 P-N 结（发射极）。

### 磷扩散（N型发射极，用于P型衬底）

工业最主流方案：**POCl₃ 液态源扩散**

```
工艺流程：
硅片 → 装入石英管式炉 → POCl₃ 被 N₂ 鼓泡携带进入炉管
       → POCl₃ + O₂ → P₂O₅ 沉积于硅片表面
       → P₂O₅ + Si → SiO₂ + P（磷扩散进入硅）
       → 驱入步骤（Drive-In）：高温下磷均匀化
       → 冷却取出
```

**关键参数：**
| 参数 | 典型值 |
|------|------|
| 扩散温度 | 820~900°C |
| 扩散时间 | 20~60 min |
| 结深（Junction Depth） | 0.3~1 µm |
| 方块电阻（Sheet Resistance） | 60~120 Ω/sq（Al-BSF/PERC前侧） |
| 磷玻璃（PSG）层 | 需后续HF酸蚀去除 |

### 硼扩散（P型发射极，用于N型衬底）

- 气态源：BCl₃ 在 800~1100°C 与 O₂ 反应生成 B₂O₃，再扩散入硅
- 固态源：硼硅玻璃（BSG）通过 PECVD 预沉积，再高温驱入
- TOPCon 电池中，硼扩散形成前侧 P+ 发射极

### 磷硼共扩散（Co-Diffusion）
- 同时沉积 BSG（硼源）和 PSG（磷源），一步高温工序完成双面掺杂
- 减少工序步骤，提升产量

---

## 2. 边缘隔离（Edge Isolation）

磷扩散是**绕镀**工艺，会在硅片四周和背面形成寄生 N 层，导致 P-N 结短路，必须隔离。

| 方法 | 描述 |
|------|------|
| 激光刻蚀 | 激光在硅片边缘烧掉扩散层（主流） |
| 等离子刻蚀 | CF₄+O₂ 等离子去除边缘和背面 N 层 |
| 机械切割 | 切除边缘，材料损耗较大 |
| 湿法腐蚀（背靠背浸腐蚀） | 两片硅片背对背只腐蚀边缘 |

---

## 3. 减反射涂层（Anti-Reflection Coating, ARC）

目的：降低硅片表面反射（裸硅反射率 ~35%），增加光吸收。

### 氮化硅（SiNₓ:H）——工业主流

**沉积方法：PECVD（等离子增强化学气相沉积）**

```
反应方程式：
3SiH₄ + 4NH₃ → Si₃N₄ + 12H₂

实际沉积：非化学计量比薄膜 SiₓNᵧ:H（含大量氢）
```

| 参数 | 典型值 |
|------|------|
| 沉积温度 | 350~450°C（PECVD） |
| 膜厚 | ~75~80 nm |
| 折射率 n | ~2.0（优化减反射） |
| 颜色 | 典型蓝色（视角/厚度变化） |
| 功能 | 减反射 + 体钝化（H进入硅片中性化缺陷） + 表面钝化 |

**SiNₓ:H 含氢特性的额外优势**：氢原子在后续烧结时扩散进入硅体，钝化晶界和体缺陷，对多晶硅效果尤为显著（体钝化效果）。

### 二氧化钛（TiO₂）——早期方案
- 减反射效果好，工艺简单（常压 CVD 或喷涂）
- 无表面/体钝化效果，现已被 SiNₓ 取代

### 叠层减反射膜（双层 DARC）
- 如 MgF₂/ZnS 或 SiO₂/SiNₓ 叠层，可进一步将反射率降至 < 3%
- 主要用于高效实验室电池或空间电池

## 4. 金属化（Metallization）

目的：形成前、后电极，实现载流子收集与外部连接。

### 丝网印刷（Screen Printing）——工业标准
详见：[05_screen_printed_cells.md](05_screen_printed_cells.md)

### 关键电极参数
| 参数 | 典型值（丝印） |
|------|-------------|
| 正面指栅线宽度 | 30~60 µm（先进工艺可达 14 µm） |
| 指栅间距 | 1.5~3 mm |
| 正面遮光损耗 | 3~10% |
| 背面铝膏覆盖率 | 全面积（Al-BSF）/ 局部开口（PERC） |

---

## 5. 烧结（Co-firing / Firing）

丝网印刷完成后，电池进入**烧结炉**（Belt Furnace / IR Furnace）：

```
烧结曲线（典型）：
150~400°C   有机物挥发（烧结粘结剂/有机载体）
500~600°C   玻璃料软化
700~850°C   峰值温度（Peak Firing Temperature）
             - 正面银浆烧穿 SiNₓ 层，与硅形成欧姆接触
             - 背面铝浆与硅合金化，形成 Al-BSF 或局部接触
快速冷却
```

**峰值温度控制至关重要**：
- 过低：接触电阻高，FF 下降
- 过高：铝/银穿刺 P-N 结，造成漏电

---

## 6. 测试与分选（Testing & Sorting）

成品电池在标准测试条件（STC）下测量 I-V 曲线：
- 光照强度：1000 W/m²
- 温度：25°C
- 光谱：AM1.5G

关键参数：Voc（开路电压）、Isc（短路电流）、FF（填充因子）、η（效率）

按效率和外观分档（Binning），供组件厂配货。

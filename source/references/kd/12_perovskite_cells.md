# 12 钙钛矿太阳能电池

> 来源：[Nature Reviews Clean Technology 2025](https://www.nature.com/articles/s44359-025-00128-z) | [RSC Energy & Environmental Science 2025](https://pubs.rsc.org/en/content/articlehtml/2025/ee/d4ee05613b) | [MDPI Energies 2024](https://www.mdpi.com/1996-1073/17/24/6344) | 学术文献综合

## 1. 概述与发展历程

钙钛矿太阳能电池（Perovskite Solar Cell, PSC）是近十年光伏领域最受关注的新兴技术。

| 年份 | 事件 |
|------|------|
| 2009 | 首次用于太阳能电池，效率 3.8%（Kojima 等，JACS） |
| 2012 | 全固态钙钛矿电池出现，效率 9.7% |
| 2016 | 实验室效率突破 20% |
| 2023 | 单结实验室效率 26.1%（KAUST） |
| 2024 | 单结实验室效率达 26.7%（KAUST，p-i-n） |
| 2025 | 单结效率 26.7%，叠层突破 34.5%；商业化元年，GW 级产线宣布 |
| 2026/03 | 晶科 + NUS 钙钛矿/TOPCon 叠层 **32.76%**（大面积） |

## 2. 钙钛矿材料

### 2.1 晶体结构（ABX₃）

```
钙钛矿结构：ABX₃

A = 有机或无机阳离子：
    MA（甲铵，CH₃NH₃⁺）/ FA（甲脒，CH(NH₂)₂⁺）/ Cs⁺
    
B = 二价金属阳离子：
    Pb²⁺（主流，高效）/ Sn²⁺（无铅替代，效率较低）
    
X = 卤素阴离子：
    I⁻ / Br⁻ / Cl⁻（混合卤素可调带隙）
```

### 2.2 代表性钙钛矿组合

| 材料 | 带隙（eV） | 特点 |
|------|----------|------|
| **MAPbI₃**（甲铵碘化铅） | 1.55 | 最早研究体系，稳定性差 |
| **FAPbI₃**（甲脒碘化铅） | 1.48 | 最接近最优带隙，热稳定性更好 |
| **Cs/FA 混合（CsFAPbI₃）** | 1.5~1.55 | 目前高效稳定主流组合 |
| **三元 Cs/MA/FA** | 可调 | 效率与稳定性综合最优（实验室主流） |
| **Cs₂AgBiBr₆（无铅双钙钛矿）** | 1.95 | 无铅方向，效率仍低 |
| **FASnI₃（锡基）** | 1.41 | 无铅，Sn²⁺ 氧化问题未解决 |

### 2.3 带隙可调性（叠层优势）

钙钛矿带隙通过调节卤素比例（I/Br/Cl）连续可调（**1.2~3.0 eV**），这是其作为叠层顶电池的核心优势：

| 叠层组合 | 顶电池带隙 | 底电池带隙 | 理论效率上限 |
|---------|---------|---------|-----------|
| 钙钛矿/硅（单结硅 1.12 eV） | ~1.7 eV | 1.12 eV | ~44% |
| 钙钛矿/钙钛矿 | 1.8 eV | 1.2 eV | ~45% |
| 三结（钙钛矿/钙钛矿/硅） | 2.0/1.6 eV | 1.12 eV | >50% |

## 3. 电池结构

### 3.1 n-i-p（正式结构，Regular Structure）

```
金属电极（Au/Ag）
    ↓
HTL（空穴传输层）：Spiro-OMeTAD / PTAA
    ↓
钙钛矿吸收层（~400~600 nm）
    ↓
ETL（电子传输层）：TiO₂（介孔/致密）/ SnO₂
    ↓
FTO 透明导电玻璃
```

- 历史上效率最高的结构
- TiO₂ 要求 **高温烧结（>450°C）**，不兼容柔性衬底和硅底电池
- 滞后效应（Hysteresis）较明显

### 3.2 p-i-n（倒置结构，Inverted Structure）—— 2025 年主流

```
金属电极（Ag/Al）
    ↓
ETL（电子传输层）：PCBM / SnO₂ / C₆₀
    ↓
钙钛矿吸收层（~400~600 nm）
    ↓
HTL（空穴传输层）：PEDOT:PSS / NiOₓ / 自组装单分子层（SAM）
    ↓
ITO 透明导电玻璃/衬底
```

**p-i-n 已成 2025 年主流，原因：**
- 全低温工艺（**< 200°C**），兼容硅异质结（HJT）底电池
- 滞后效应更小，稳定性更优
- 更适合大面积印刷工艺
- 2025 年单结 p-i-n 效率已超 n-i-p 历史记录

## 4. 制造工艺

### 4.1 实验室/小面积工艺

**旋涂法（Spin Coating）**：
- 将钙钛矿前驱体溶液旋涂到衬底
- 高速旋转（3000~6000 rpm，30~60 s）形成均匀薄膜
- 反溶剂淬火（Anti-solvent Quenching）辅助成核
- 优点：工艺简单，面积 < 1 cm² 效率最高
- 缺点：材料利用率低（< 10%），不可扩展

### 4.2 可扩展大面积工艺（工业化方向）

| 工艺 | 原理 | 面积可扩展性 | 效率 | 成熟度 |
|------|------|-----------|------|--------|
| **刮涂（Blade Coating）** | 刮刀在基板上刮涂浆料 | 高（可连续） | ~23% | 实验室成熟 |
| **狭缝挤出（Slot-die Coating）** | 精密涂布头线性涂布 | 高，**工业最优** | ~22.8%（23.25 cm²） | 量产主力方向 |
| **喷涂（Spray Coating）** | 气雾化喷涂 | 高 | ~20% | 低成本，均匀性待提升 |
| **丝网印刷（Screen Printing）** | 图案化印刷 | 中 | ~18~20% | 特定层使用 |
| **气相沉积（Vapor Deposition/Thermal Sublimation）** | 真空热蒸发共蒸 | 高，保形性好 | ~24%+ | 工业化加速 |
| **喷墨打印（Inkjet Printing）** | 精确图案化 | 高 | ~21%+ | 研究阶段 |

### 4.3 关键制备挑战

**薄膜质量控制：**
- 前驱体溶液中加入 **MBT（2-巯基苯并噻唑）配体**：稳定中间相、防止空洞形成，使大面积钙钛矿膜晶粒均匀（NUS/晶科 2026 年突破关键）
- 退火条件（温度、气氛、速率）影响结晶质量和载流子寿命
- 大面积膜的均匀性（温度梯度、溶剂挥发均匀性）

**从手套箱到大气制备：**
- 实验室在氮气/氩气手套箱制备，不可扩展
- 2025 年工业化目标：环境空气（Ambient Air）制备，降低成本

## 5. 各功能层材料

| 层 | n-i-p 材料 | p-i-n 材料 | 功能 |
|----|-----------|-----------|------|
| **HTL** | Spiro-OMeTAD（高效）/ PTAA | PEDOT:PSS / NiOₓ / SAM（CF-SAM, Me-4PACz） | 空穴传输，电子阻挡 |
| **ETL** | 致密 TiO₂ + 介孔 TiO₂（高温）/ SnO₂（低温） | PCBM / C₆₀ / SnO₂ | 电子传输，空穴阻挡 |
| **钙钛矿** | CsFAMAPbI₃₋ₓBrₓ（混合卤素） | 同左 | 光吸收，产生载流子 |
| **透明电极** | FTO（n-i-p前） / ITO（p-i-n前） | ITO | 导电 + 透光 |
| **金属电极** | Au（实验室）/ Ag | Ag / Al / Cu | 收集电流 |

### HTL 重要进展（2025年）

**自组装单分子层（SAM，Self-Assembled Monolayer）**：
- 取代厚有机 HTL（Spiro/PTAA），仅需单分子层厚度
- 代表材料：Me-4PACz、2PACz、CF-SAM（含氟）
- 2025 年 p-i-n 记录效率使用 SAM-HTL
- 原位配位 HTL 策略（Nature Communications 2025）：将 HTL 材料掺入钙钛矿前驱体，在成膜过程中原位自发到界面，提升界面质量

## 6. 稳定性挑战

钙钛矿商业化最大障碍，需达到 **≥ 25 年**使用寿命。

| 降解因素 | 机制 | 应对策略 |
|---------|------|---------|
| **水分/湿气** | 钙钛矿水解，MAPbI₃+H₂O → 分解 | 封装改进（低水汽背板）、疏水界面层 |
| **热稳定性** | FA/MA 有机阳离子挥发（>85°C）| 无机替代（Cs 掺杂）、稳定晶相（δ→α）|
| **光照降解** | 卤素离子迁移，界面重组 | 界面钝化，降低界面态密度 |
| **氧气** | 氧化 Spiro/金属电极 | 封装隔氧，无氧 HTL |
| **离子迁移** | 内置电场驱动卤素离子移动 | 2D/3D 混合钙钛矿，阻挡层 |
| **铅毒性** | Pb²⁺ 水溶性强，泄露风险 | 封装强化，无铅/低铅钙钛矿研究 |

**加速寿命测试标准**（ISOS 协议）：

| 测试 | 条件 | 目标 |
|------|------|------|
| 湿热（Damp Heat） | 85°C/85%RH，1000h | T80（功率降至初始 80%）> 1000h |
| 热循环 | -40°C → +85°C，200 次 | 无分层/裂纹 |
| 光稳定性（MPP 追踪） | AM1.5G，1 sun，25°C，1000h | T80 > 1000h |
| 室外测试 | 自然光照，多气候带 | 25 年 P90（90% 概率满足功率要求） |

## 7. 叠层电池（Tandem）

### 7.1 钙钛矿/硅叠层

```
结构（p-i-n 钙钛矿顶电池 + TOPCon/HJT 硅底电池）：

ITO（减反射）
钙钛矿顶电池（带隙 ~1.68 eV）
    [FACs 混合钙钛矿/SAM-HTL/SnO₂-ETL]
隧道结/重组层（Recombination Layer）
硅底电池（HJT 或 TOPCon，带隙 1.12 eV）
ITO
背面 Ag 栅线
```

**关键效率记录（2024~2026年）：**

| 机构 | 效率 | 年份 | 面积 |
|------|------|------|------|
| KAUST | 33.9% | 2024 | 1 cm² |
| LONGi | 33.9% | 2023 | 1 cm² |
| EPFL/Csem | 31.25% | 2023 | 1 cm² |
| 晶科 + NUS/SERIS | **32.76%** | 2026/03 | 大面积（工业TOPCon片） |
| 实验室记录 | **34.5%+** | 2025 | 小面积 |

### 7.2 叠层商业化挑战

| 挑战 | 描述 |
|------|------|
| 电流匹配 | 顶/底电池短路电流需匹配，带隙偏差影响输出 |
| 大面积制备 | 钙钛矿膜大面积均匀性 >> 小面积难度大 |
| 接线盒/封装兼容 | 两端（2T）与四端（4T）叠层各有优劣 |
| 长期稳定性 | 钙钛矿自身寿命不足 + 叠层额外界面降解 |
| 认证标准 | IEC 61215/61730 未针对叠层建立专用标准 |

## 9. 与晶硅技术的比较

| | 晶硅（TOPCon/HJT） | 钙钛矿单结 | 钙钛矿/硅叠层 |
|--|------|--------|--------|
| **效率（实验室）** | 26.7%（HJT）| 26.7% | 34.5%+ |
| **效率（量产）** | 24~26% | <20%（早期） | <30% |
| **成本** | 低（成熟产业链） | 潜力很低 | 目前高 |
| **寿命** | 25~30 年 | < 25 年（待验证） | 待定 |
| **稳定性** | 成熟 | 主要挑战 | 叠加挑战 |
| **铅毒性** | 无 | 有（Pb 基主流） | 有 |
| **制造设备** | 成熟产业链 | 全新设备 | 硅线基础+新设备 |

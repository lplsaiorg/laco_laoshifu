# 领域相关程序变更检查模板

按实际变更填写，不为无关项新增功能或测试。

| 检查点 | 变更依据/实现位置/验证结果 |
|---|---|
| 业务对象、适用技术路线、工序、设备层级 | |
| 真实字段映射、唯一键、连接基数、配方版本 | |
| 时间来源、时区、区间边界、跨班/跨日、迟到事件 | |
| 原值与单位、压力基准、气体标准状态 | |
| 状态字典、冲突优先级、未知/缺失区间、报警与停机关系 | |
| 投入/产出/合格片数、返工、重测、计数器复位 | |
| 指标公式、分母、聚合权重、口径出处和版本 | |
| 原文典型参数是否误入代码常量、报警或验收阈值 | |
| 可观察的失败提示、原始记录与处理日志 | |
| 与本次行为变更直接相关的边界测试和结果 | |
| 用户可见行为、输出格式、兼容性与未决项 | |

参考知识库文件与章节：（填写）。缺少现场定义时把可替换规则置于显式配置/接口，不用示例映射冒充正式规则。

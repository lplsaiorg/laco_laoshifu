# KD 业务上下文

让回答使用本项目的光伏工艺语境，并说明资料能支持到哪里。

## 找到知识库

先解析本 `SKILL.md` 的真实路径（处理 `.agents/skills` 的目录联接），从所在目录逐级向上寻找同时含 `source/README.md` 和 `source/tools/kb.py` 的项目根。通常本技能实体在 `skills/kd-context/`，知识库在 `../../source/`。不要以当前工作目录或目录联接的表面层级猜路径。

读取 [知识库入口](../../source/README.md)，再利用可用的 `source/catalog.json` 选择当前问题需要的文件；索引可校验，不是定位知识库的前提。优先读取相应知识摘要与原文的相关章节，不必载入全部资料。

## 按问题取证

| 问题 | 优先入口 |
|---|---|
| 电池技术路线、工序前后关系 | [工艺地图](../../source/knowledge/process-map.md) |
| 硼扩散、氧化、LPCVD、PECVD 和设备层次 | [设备知识](../../source/knowledge/equipment.md) |
| IV、EL、PL、寿命、材料与质量 | [测试与材料](../../source/knowledge/quality-and-materials.md) |
| 中文简称、英文缩写、数据集代号与多别名 | `source/glossary.json`、[名称对照表](../../source/knowledge/name-crosswalk.md) |
| 资料矛盾或现场定义不足 | [缺口与冲突](../../source/knowledge/gaps-and-conflicts.md) |

在已定位的项目根运行 `python source/tools/kb.py search "硼扩散" --limit 5`；中文术语和英文缩写可分别检索。检索结果是定位线索，引用数字与结论前打开命中的原文段落。

`abbr` 同时查询中文简称、英文缩写和数据集代号，例如 `python source/tools/kb.py abbr 硼扩`、`abbr PE`、`abbr BK`、`abbr PK`（后三项使用相同命令前缀）。用 `python source/tools/kb.py abbr 硼扩散` 可从概念查看其多个简称；不要求概念必须有英文缩写。不带查询词列清单，`--category testing` 按类别查看，`--json` 返回结构化结果；英文全称、中文名与别名也可检索。

解释简称时同时看 `short_names` 的 `kind`、`status`、`scope` 和 `sources`，以及用途与备注。短代号的含义取决于厂区、数据集或字段；不能把 LP 猜作磷扩散、按拼音猜 TX 等代号。候选可展示并标明待确认，不自动作为同义词扩展或全局替换。数据集局部证据不构成全厂规则。`full_name_status=curated_translation` 表示整理补充的全称或译名，不能称作原文明确给出。

同一缩写可有多个中文含义，按 [名称消歧流程](../../source/workflows/name-disambiguation.md) 先列候选。`abbr` 及其 `ambiguity/next_action` 只提供候选和处理提示，不代替语义判断。本次用户已明确且适用的定义直接使用，不重复问；其他情况结合工序设备、文件路径、字段邻列、单位、技术路线和文档版本推断，注明“上下文推断”及依据，不能按频率或首条结果机械选取。

仍有多个合理含义、证据不足或相互冲突时，必须简短确认：列出 2–3 个候选，或请求原句/来源。答复前不做依赖该含义的字段合并改名、计算或最终技术结论，继续独立检查。此前 PK=磷扩散只适用于已确认语境，新数据源需重新核对；未请求维护时，不将本次推断或确认推广全库。

旧 `aliases` 含相关检索提示词，不等于同概念名称。例如气源与扩散工序、隧穿层与电池技术是相关对象；严格简称对照以明确名称及 `short_names` 为准。

索引缺失、过期或工具不能运行时，读取 README 并用 `rg -n "关键词" source/references/kd source/knowledge source/workflows` 继续查证；缩写可直接查 `source/glossary.json`。将关键词换成实际术语。普通查询不因此改写原文或刷新快照；维护任务按维护流程重建索引。

## 使用证据

- 原文快照在 `source/references/kd/`；摘要属于整理层，发生分歧时同时列出原文位置与冲突，不能把参考范围改写成统一现场标准。
- 区分“原资料记载”“基于资料的解释或建议”“待现场确认”。数字保留单位、工艺步骤、技术路线、资料年份；实验纪录、量产水平和组件效率分别表述。
- TOPCon 的 LPCVD 与 PECVD 是不同路线；同名压力或温度要核实所属工步。不同压力单位先换算再比较，不能将 `110 Torr` 当作 `110 Pa`。
- 本库未提供工厂实际数据字典、OEE 状态映射、计划时间分母、报警阈值或生产配方审批。缺失信息只限制依赖它的结论；仍可解释工艺、列出证据与待确认项。
- 将事实的文件名与章节放在结论附近；如回答涉及时效性市场数据，标明本地资料年份。用户要求当前情况时另取当前来源，并说明新增来源。

数据、文档或代码任务还应读取 `source/workflows/` 中对应工作流。不要把本技能当作执行生产设备控制或更改现场标准的授权。
